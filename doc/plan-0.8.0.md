# План 0.8.0 — Действия всех Комнат, места за столом, Рация и Честный ИИ

Документ подготовки выпуска 0.8.0 (этап 8 `doc/roadmap.md`). Метки шагов — «В8-<шаг>-<номер>».
Правила и границы — `AGENTS.md`; механика — `doc/rules.md` (ссылки «стр. N»).

Результат выпуска: партия на 1–5 мест, где пустые места занимают боты. Боты:
- видят ровно то, что видел бы игрок за этим местом;
- общаются через Рацию (Заявления, Намерения, Просьбы);
- судят о других прежде всего по делам, а не по словам;
- различаются характером.

## 1. Сверка с кодом и правилами (что есть сейчас)

### 1.1. Действия Комнат

`logic/roomAbilities.ts` реализует 13 Комнат, остальные попадают в `default` и отклоняются.

| Комната | Правило (стр. 24–26) | Статус |

| Оружейная, Радиорубка, Лазарет, Генератор, Пожарная безопасность, Склад, Улей, Лаборатория, Операционная | базовые «1» | есть |
| Спасательные отсеки A/B, Криогенный отсек, Система блокировки капсул | эвакуация | есть |
| Каюты | пассивно: 6 карт вместо 5 | есть (`cardsPayment.ts`) |
| Комната, покрытая Слизью | пассивно: Слизь при входе, без Поиска | есть частично — проверить маркер при входе |
| **Машинный Отсек 01/02/03** | [2] Проверка Двигателя (тайно) | **нет** — есть только Починка/Повреждение картой (`setEngineState`) |

| **Комната Наблюдения** | [2] тайно посмотреть неисследованную Комнату и жетон | **нет** (логика подглядывания есть в `peekRoom`) |

| **Столовая** | [2] вылечить 1 Лёгкую + по желанию скан | **нет** |
| **Душевая** | [2] сбросить Слизь + по желанию скан | **нет** |

Базовое действие **[1] Обмен** (стр. 12) тоже **не реализовано**.

### 1.2. Двигатели и объявление о перестановке (Р-4)

- `setEngineState` (карта Ремонта или Инструменты):
  - пишет `ENGINE_TOGGLED` с `orderChanged`;
  - в срезе чужих игроков `isWorking = null`, а `orderChanged` публичен.

  Это и есть обязательное объявление из Р-4, его нужно только показать в интерфейсе и Рации как отдельное неотменяемое сообщение.
- Проверявший Двигатель (`inspectedEngines`) видит в срезе **текущее** состояние.

  Это не утечка: смена состояния всегда сопровождается публичным объявлением, и знавший прежнее состояние выводит новое сам (перестановка = противоположное). Но вывод обязан уметь и бот — через свою память, а не через подсказку среза. Черта «склеротик» может его «забыть» — только в памяти бота.
- Маркер Курса публичен, карта Координат скрыта (`sanitizer.ts`) — по правилам.

### 1.3. Заявления

`ACTION_CLAIM` и `ClaimEvent` объявлены в `types/actions.ts`, `claimsLog` есть в `GameState`. Движок отклоняет `ACTION_CLAIM` (`ACTION_NOT_IMPLEMENTED`). В `ClaimEvent` поле `timestamp: number` — для воспроизводимости по сиду заменяется номером раунда и порядковым номером.

### 1.4. Режимы

- `GameMode` = `SOLO | SEMI_COOP | COOP`, но `resolveGameMode` возвращает только первые два.
- **Соло (стр. 27): «количество предметов в Комнатах снижено в два раза с округлением в большую сторону» — не реализовано** (`setup.ts` берёт `token.itemsCount` как есть).
- Полный Кооператив (стр. 27: Соло/Кооп Цели у каждого, победа — все Цели и ≥1 выживший, Оживление в Лазарете «АвтоДок») не реализован.

### 1.5. Подготовка экипажа (стр. 8)

- **Оригинал:**
  - карты Памятки случайно задают номера игроков (шаг 14);
  - Цели раздаются **до** выбора Персонажа (шаг 16, «вы можете выбрать Персонажа, который имеет наилучшие шансы»);
  - Драфт (шаг 17): игрок 1 открывает 2 случайные карты Персонажей, берёт одну, вторую замешивает обратно, затем игрок 2 и т. д.
- **Сейчас:** человек свободно выбирает класс (`chosenCharacterClass`), Цели раздаются после.

### 1.6. Транспорт и места

`IGameTransport` отдаёт срез одного игрока. Интерфейс ведёт одного Персонажа, остальные места не ходят. Сервера нет (этап 10): удалённое подключение игроков в 0.8.0 невозможно. Модель мест делается сразу под сервер, но удалённые места включатся в 0.10.0.

## 2. Принципы выпуска

1. **1:1.** Боты играют по тем же правилам через тот же `GameEngine.processAction`: никаких поблажек и особых действий. Рация — цифровая форма разговора за столом: не Действие, ничего не стоит, правил не меняет.
2. **Честность среза.** Бот получает только `filterStateForPlayer(state, botId)`, публичную Рацию и свою память.
3. **Детерминизм.** Мысли бота берут случайность из своего потока `ai:<playerId>` и не сдвигают чужие потоки. Партия с ботами воспроизводится по мастер-сиду при тех же действиях людей.
4. **Изоморфность.** ИИ живёт в `packages/shared/src/ai/`, без DOM, React, Node. На сервер этапа 10 переносится без изменений.
5. **Настройки в одном файле.** Все числа поведения — в `ai/botTuning.ts`, фразы — в `ai/botPhrases.ts`, описание ручек — в `doc/bots.md`.
6. **Отладка не течёт.** Инспектор ботов живёт только за `IS_DEV`, CI проверяет его отсутствие в бандле.

> 4. Декомпрессия снимается, как только любая Дверь её Комнаты перестаёт быть Закрытой (открыта или разрушена).

**Цель:** все Комнаты поля делают то, что написано в правилах, иначе ботам не о чем заявлять и нечем помогать.

1. **В8-1-1 Машинный Отсек 01/02/03 [2]** — тайная Проверка Двигателя:
   - публичная запись «X проверил Двигатель N» без результата;
   - игрок добавляется в `inspectedEngines`;
   - проверка возможна при маркере Неисправности (стр. 26);
   - Починка/Повреждение остаётся за картой Ремонта и Инструментами.
2. **В8-1-2 Машинное Отделение [2]** — тайно все 3 Двигателя; менять состояние здесь нельзя.
3. **В8-1-3 Мостик [2]** — выбор режима:
   - «Проверка Координат» — тайно, `inspectedCoordinates`, публичная запись без содержания;
   - «Установка Курса» — перенос маркера, публично. Запрещена при Персонаже в Анабиозе и при Чужом на Мостике (стр. 26), отказ — `EngineError` с причиной.
4. **В8-1-4 Комната Наблюдения [2]** — тайно оборот неисследованной Комнаты и жетон Исследования (переиспользовать `peekRoom`), публично — только какую Комнату смотрели.
5. **В8-1-5 Центр Управления [2]** — выбрать Комнату и набор Дверей в её Коридорах: открыть / закрыть по выбору. Лимит жетонов Дверей и Разрушенные Двери — по общим правилам.
6. **В8-1-6 Контроль Воздушных Шлюзов [2]** — Экстренная Декомпрессия:
   - выбор другой жёлтой Комнаты без Разрушенных Дверей в её Коридорах; все Двери закрываются, кладётся жетон Декомпрессии, Пожар в Комнате снимается;
   - открытие любой её Двери до конца Фазы Игроков снимает жетон;
   - в конце Фазы Игроков при всех закрытых Дверях гибнут все в Комнате (Персонажи — через `killPlayer`, Чужие — снятие), жетон снимается.

   Новое поле состояния — `ship.decompression: { roomId, startedBy } | null`.
7. **В8-1-7 Столовая [2]** — вылечить 1 Лёгкую Травму и по желанию скан Заражения (общая процедура Сканера, как в Операционной: Личинка или смерть).
8. **В8-1-8 Душевая [2]** — сбросить Слизь и по желанию тот же скан; Пожар не снимается.
9. **В8-1-9 Комната Слизи** — проверить и покрыть тестом получение маркера при входе.
10. **В8-1-10 Действие [1] Обмен** (стр. 12):
    - инициатор предлагает Предметы или Объекты участникам в своей Комнате; каждый отвечает (`pendingDecision` по очереди участников);
    - сделка применяется, если обе стороны согласны; можно отдать даром;
    - Действие тратит только инициатор;
    - Боезапас отдельно не передаётся (Р-2), Оружие переходит вместе со своим Боезапасом.
11. **В8-1-11 Соло: Предметы вдвое** (стр. 27): счётчик Предметов из жетона Исследования делится пополам с округлением вверх (1–2 → 1, 3–4 → 2).
12. **Интерфейс:** панели инспектора для новых Комнат, выбор Дверей на карте для Центра Управления и Декомпрессии, окно Обмена с двумя колонками («отдаю / получаю»), жетон Декомпрессии на поле.
13. **Тесты:** на каждую Комнату — успех и запреты (Неисправность, Бой, неисследованная, особые запреты Мостика). Декомпрессия: отмена открытием и гибель. Обмен: согласие, отказ, дар, запрет Боезапаса. Соло-округление. Срез: результат Проверок виден только проверившему.

      - **Драфт (стр. 8, шаг 17):** по номерам игроков каждый открывает 2 случайные карты Персонажей, берёт 1, вторую замешивает обратно;
      - **Свободный выбор:** люди выбирают из всех ролей, занятые роли помечены и недоступны, **боты выбирают последними** из оставшихся;
      - не успевший выбрать человек получает роль случайно: в Драфте — одну из двух своих открытых карт, в свободном выборе — из свободных. Боты выбирают роль по своей полезности для Целей (стр. 8: «вы можете выбрать Персонажа, который имеет наилучшие шансы»).

   `createInitialGameState` получает готовый результат подготовки: места, номера, Цели, роли. Вся случайность подготовки воспроизводится по сиду.
4. **В8-2-4 Оркестратор ходов.** `SeatController` в транспорте после каждого действия определяет, чей ход (`activePlayerId` или `pendingDecisionPlayerId`):
   - `LOCAL_HUMAN` — ждёт интерфейс;
   - `BOT` — вызывает бота;
   - защиты: предел шагов, три отказа подряд → безопасный Пас.

   Через контроллер проходят и все ожидаемые не от активного игрока решения: выбор Цели при Первом Контакте, «Стальные нервы», ответы на Обмен, согласие в «Огне на подавление» и «Заградительном огне», «Отставить» (Р-7, пункт В8-2-6).
5. **В8-2-5 Темп.** Бот ходит, только когда очередь презентации пуста (`isPresentationIdle`), с паузой между Действиями и кнопкой «быстрее» в HUD.
6. **В8-2-6 Действия с участием другого игрока (Р-7):**
   - «Огонь на подавление» и «Заградительный огонь»: запрос согласия у указанного игрока через `pendingDecision` этого места; без согласия эффект не применяется;
   - «Отставить» (текст карты: «Сбросьте эту карту, чтобы отменить Действие другого Игрока в вашей Комнате (этот Игрок оплачивает Цену отмененного Действия) ИЛИ Отмените Действие «Отставить» другого Игрока»): после объявления Действия игроки в той же Комнате получают окно реакции; отменённое Действие не выполняется, но его Цена оплачена; «Отставить» можно отменить встречным «Отставить» (цепочка реакций);
   - снимается ограничение README «Согласие второго игрока не запрашивается».
7. **Тесты:**
   - 1 человек + 4 бота: партия идёт по кругу;
   - решения при Первом Контакте раздаются всем местам;
   - случайное назначение ролей воспроизводимо;
   - Соло включает правило Предметов;
   - Драфт: 2 карты, выбор, возврат второй, порядок по номерам; свободный выбор: занятая роль отклоняется, боты выбирают последними; тайм-аут выбора — случайная роль;
   - Цели розданы до выбора роли;
   - согласие и отказ в «Огне на подавление» и «Заградительном огне»; «Отставить» отменяет Действие с оплатой его Цены, встречное «Отставить» отменяет первое.

1. **В8-3-1 Сообщения.** `GameState.comms: CommsMessage[]` вместо `claimsLog`:
   - сообщения публичны, срез отдаёт их целиком;
   - каждое имеет `round`, порядковый номер, автора, адресата (`ALL` или игрок) и тип.

   Действие `ACTION_COMMS` не тратит Действий и карт.
2. **В8-3-2 Типы сообщений:**
   - **Системное объявление (обязательное, Р-4):** «Жетоны Двигателя N переставлены» — генерирует движок из `ENGINE_TOGGLED.orderChanged`. Игрок не может ни подавить его, ни подделать.
   - **Заявление:**
     - Двигатель N исправен или сломан;
     - «я починил», «я повредил», «я не трогал»;
     - Координаты: пункт назначения при маркере A–D;
     - Курс ведёт к Земле или не к Земле;
     - «Комната X — это Y» (после Наблюдения);
     - «я не заражён»;
     - «у меня есть Предмет Y».

     Заявить можно что угодно, без проверки: это законный блеф.
   - **Намерение:**
     - исследую;
     - ищу Комнату (тип);
     - иду к Двигателям или Мостику;
     - иду лечиться;
     - иду в Анабиоз или к Капсуле N;
     - прикрываю игрока X;
     - иду в Комнату R.

     Намерение хранит цель на графе, поэтому его исполнение измеримо.
   - **Просьба:**
     - нужен Предмет (оружие, Энергозаряд, Увеличенный магазин, лечение, конкретный Предмет);
     - помогите убить Чужого в R;
     - проверьте Двигатель N или Координаты;
     - откройте или закройте Дверь в коридоре C;
     - потушите Пожар в R;
     - подождите меня в Капсуле;
     - не запускайте Самоуничтожение.

     У Просьбы есть срок в раундах (настройка).
   - **Ответ:** «помогу» (создаёт **обязательство**), «не могу». Игнорирование — отсутствие ответа до конца срока.
   - **Реакция:** «не верю» (ссылка на Заявление), «спасибо» (ссылка на действие или сообщение).
3. **В8-3-3 Лимиты (Р-9)**, за свой ход:
   - до 3 обычных сообщений: Заявления, Намерения, Реакции;
   - Просьбы — отдельный лимит, не больше 1;
   - ответы на Просьбы — в свой ход, вне лимитов;
   - системные объявления — вне лимитов.

   Превышение лимита или сообщение вне своего хода отклоняется явной ошибкой. Значения лимитов — в настройках Рации.
4. **В8-3-4 Учёт обязательств.** Движок сам отмечает выполнение по публичному журналу:

   | Просьба | Чем выполняется |
   |---|---|
   | проверить Двигатель | Проверка в нужном Отсеке |
   | помочь убить | вход в Комнату и атака |
   | нужен Предмет | Обмен с передачей подходящего Предмета |
   | Дверь | нужное состояние, выставленное этим игроком |
   | Пожар | тушение |
   | подождать в Капсуле | ожидание до прихода |

   Статусы обязательства: `OPEN → FULFILLED | BROKEN | EXPIRED`. Все статусы публичны.
5. **Тесты:** лимит, чужой ход, неверный адресат, несуществующая цель — явные ошибки. Системное объявление нельзя отправить действием. Выполнение и нарушение обязательств.

### Шаг 5 (В8-5). Ядро бота: граница честности, память, характер, настройки

1. **В8-5-1 Граница.** `packages/shared/src/ai/**` может импортировать только `types/sanitized`, `types/actions`, `data/`, `utils/` и чистые запросы графа. ESLint `no-restricted-imports` запрещает `GameState`, `logic/fsm`, `logic/sanitizer`, `logic/setup`.
2. **В8-5-2 Интерфейс:**

   BotAgent.decide(view: SanitizedGameState, mind: BotMind) → { action: EngineAction; mind: BotMind; speech: CommsDraft[] }

3. **В8-5-3 Память `BotMind`** (сериализуемая, со своей версией схемы, в сохранении сессии, не в `GameState`):
   - черты и мораль;
   - счётчик потока `ai`;

4. **В8-5-4 Наблюдатель.** Новые записи журнала и Рации переводятся в факты:

5. **В8-5-5 Убеждения о Двигателях и Курсе.** Вероятность «исправен» по каждому Двигателю складывается из:

   - Заявлений, взвешенных доверием к автору;
   - априорной пары жетонов на подготовке.

   Координаты — распределение пункта назначения по маркерам; маркер Курса известен.
6. **В8-5-6 Поток `ai`.** Добавить поток в `RNG_STREAMS`, отдельный счётчик на бота в `BotMind`.
7. **В8-5-7 Генерация характера:**

### Шаг 6 (В8-6). Социальная модель: доверие, мораль, ложь, Просьбы

1. **В8-6-1 Модель каждого игрока — три шкалы** (Бета-распределения, «почему» хранится списком улик):
   - **Честность:** Заявление подтверждено или опровергнуто. Опровергают:
     - собственная Проверка бота;
     - противоречие двум независимым Заявлениям;
     - «я не трогал» при системном объявлении о перестановке;
     - Заявление о Курсе при несогласном переносе маркера этим же игроком.
   - **Надёжность:**
     - обещание выполнено или нарушено;
     - Намерение исполнено: прогресс по графу к объявленной цели за N ходов.
   - **Враждебность / помощь** по делам. Каталог сигналов с весами в настройках:
     - вредит: закрыл Дверь между ботом и укрытием при Чужом рядом; Пожар или граната в Комнате бота; Декомпрессия Комнаты с ботом; запуск Самоуничтожения; блокировка Капсулы; улетел, не дождавшись обещанного; повредил Двигатель после Заявления «чиню»;
     - помогает: тушил, чинил, убил Чужого в Комнате бота, отдал Предмет, открыл Дверь по Просьбе.
2. **В8-6-2 Доверие** — сводка трёх шкал, дела весят больше слов. Уличённого во лжи бот слушает со скепсисом: его Заявления почти не сдвигают убеждения, его Просьбы выполняются только при собственной выгоде. Скепсис забывается медленно, у обидчивого почти не забывается.
3. **В8-6-3 Дрейф морали** за раунд с пределом шага:
   - плюс: полученная помощь, выполненные в его пользу обещания;
   - минус: вред, пойманная ложь в его адрес, «проигрываю» (Цель стала недостижимой, 2+ Тяжёлые Травмы, Личинка).
4. **В8-6-4 Угадывание чужих Целей.** Распределение по составу колод Целей (публичному) без своих карт. Уточняется по делам:
   - носит Яйцо — «AB OVO»;
   - ходит в Радиорубку — Цели с Сигналом;
   - держит Труп — Цели с Трупом;
   - избегает или преследует игрока N — Цели «Игрок N не должен выжить».

   Если бот подозревает Цель против себя, он держит дистанцию и не ждёт этого игрока в Капсуле.
5. **В8-6-5 Политика лжи.** Бот лжёт, если выигрыш по его полезности выше, чем «цена разоблачения × шанс разоблачения». Шанс считается по публичным фактам: сколько игроков проверяли тот же Двигатель, есть ли объявления о перестановке. Бот помнит свою ложь и держит линию (кроме склеротика).
6. **В8-6-6 Ответы на Просьбы:** полезность помощи = выгода просящему × вес морали × доверие − собственная цена (риск, Действия, Предметы). «Помогу» — только если бот правда собирается, либо это сознательный обман (у лжеца, социопата, психопата). Нарушение бьёт по его репутации у всех.
7. **Тесты:**
   - лжец разоблачается Проверкой;
   - после опровержения Заявления игрока почти не влияют;
   - нарушенное обещание снижает надёжность у всех наблюдателей;
   - угаданная враждебная Цель меняет поведение.

### Шаг 7 (В8-7). Utility AI и навигация

1. **В8-7-1 Генератор допустимых действий по срезу.** Условия движка (путь, оплата, условия Комнат, символы Боя, слоты Рук) выносятся в чистые предикаты над публичными данными. Их вызывают и движок, и бот, поэтому допустимость не расходится (тест на совпадение).
2. **В8-7-2 Два уровня решений:**
   - **Желание** (раз в ход): выжить, продвинуть Цель, подготовить эвакуацию, снаряжение, разведка, узнать Двигатели или Курс, помочь, сорвать чужую игру, выполнить обещание.
   - **Действие:** кандидаты оцениваются произведением факторов с кривыми отклика. Выбор — softmax по лучшим с температурой.

   Порядок роадмапа «выживание → Цель → снаряжение → Пас» задан весами, черты их сдвигают.
3. **В8-7-3 Модель риска:**
   - шанс Контакта: грани кубика Шума, маркеры Шума, неисследованная Комната;
   - ожидаемые Раны от Чужих: публичные характеристики и Планшет Чужих;
   - Пожар, Слизь, Декомпрессия;
   - время: ходы до прыжка или взрыва против пути до Анабиоза или Капсулы.
4. **В8-7-4 A\*** по графу корабля:
   - цена ребра: Действие + риск Шума и Контакта + Пожар + Чужие + закрытая Дверь (цена открытия) + неисследованная Комната;
   - эвристика — таблица кратчайших расстояний в прыжках (21 Комната);
   - поиск ближайшей Комнаты типа X по вероятностям тайлов.
5. **В8-7-5 Планировщики Целей** — оценки близости на основе `objectiveConditions.ts` для всех 25 Целей. Пример: «Корабль должен достигнуть Земли» → 2 исправных Двигателя, Курс на Землю, Анабиоз вовремя.
6. **В8-7-6 Кооперативные действия:**
   - Проверка и Починка Двигателей;
   - Установка Курса;
   - тушение и ремонт Неисправностей;
   - Обмен Предметами (Боезапас — только вместе с Оружием, Р-2);
   - совместный Бой;
   - Двери Центра Управления против Чужих;
   - ожидание союзника в Капсуле.
7. **В8-7-7 Управление рукой:** ценность карт — боевые и классовые бережёт, учёт Заражения. Выбор карт оплаты и сброса при Пасе.
8. **В8-7-8 Решения `pendingDecision`:**
   - выбор Цели при Первом Контакте;
   - Поиск (1 из 2);
   - Сканер;
   - «Стальные нервы»;
   - Обмен;
   - запуск или ожидание в Капсуле;
   - Самоуничтожение;
   - Декомпрессия.
9. **В8-7-9 Бюджет.** Решение бота — меньше 50 мс на телефоне; при превышении контроллер переходит в Web Worker.
10. **Тесты:**
    - бот уходит из горящей Комнаты;
    - ведёт себя к Анабиозу до прыжка;
    - чинит Двигатель при своей Цели «Земля»;
    - A\* обходит Пожар и Чужих;
    - генератор совпадает с движком на случайных столах.

### Шаг 8 (В8-8). Черты, голос, сложность

1. **В8-8-1 Черты** — модификаторы настроек, без отдельного кода. Таблица — §4.
2. **В8-8-2 Голос:** банк фраз `ai/botPhrases.ts` по типу сообщения и чертам. Бот говорит, когда полезно по его полезности: Намерение перед долгим походом, Просьба при нехватке ресурса, Заявление после Проверки по политике лжи. Частота — в настройках.
3. **В8-8-3 Сложность:**
   - «Новичок» — высокая температура, слабее оценка риска, чаще склеротик;
   - «Экипаж»;
   - «Ветеран» — низкая температура, горизонт 2–3 хода, точный риск.
4. **В8-8-4 Показ черт человеку (Р-8):** черты скрыты; видны только в Инспекторе ботов за `IS_DEV`. Досье показывает только поведение.

### Шаг 9 (В8-9). Отладка, симулятор, балансировка

1. **В8-9-1 Инспектор ботов** (`IS_DEV`, dev-канал транспорта). Для каждого бота:
   - черты, мораль и её график;
   - секретные Цели;
   - убеждения о Двигателях и Курсе;
   - матрица доверия с уликами;
   - текущее желание и 5 лучших кандидатов с разбором факторов;
   - журнал своей лжи и обещаний.

   CI проверяет отсутствие в бандле.
2. **В8-9-2 Симулятор** `scripts/simulate-bots.ts` (Node, вне `shared`):
   - N партий одних ботов по сидам;
   - отчёт: победы по чертам и морали, причины гибели, длина партии, доля лжи и разоблачений, выполненные обещания, зависания.
3. **В8-9-3 Обязательные тесты:**
   - **нет подглядывания:** смена скрытого (чужие руки, порядок колод и мешка, непроверенные Двигатели, карта Координат, чужие Цели) не меняет решение бота — на сотнях случайных столов;
   - **воспроизводимость:** партия из одних ботов по одному сиду даёт одинаковый журнал;
   - **нет зависаний:** партия из одних ботов доходит до `GAME_OVER` за предел шагов;
   - **1:1:** все действия ботов — обычные `EngineAction`.
4. **В8-9-4 Балансировка:** по отчётам симулятора правится `botTuning.ts`, итоги записываются в `doc/bots.md`.

## 4. Черты характера (исходные значения в `botTuning.ts`)

| Черта | Влияние | Несовместима с |
|---|---|---|
| Паникёр | риск ×2, высокая температура, частые Просьбы, бегство из Боя | Истребитель |
| Истребитель | тяга к Бою, «помогите убить» ценит выше | Паникёр |
| Барахольщик | Поиск и хранение Предметов, неохотно отдаёт | Филантроп |
| Исследователь | бонус за неисследованное, Наблюдение, Намерения «разведка» | — |
| Перфекционист | не верит Двигателю без своей Проверки, чинит, доводит обещания | Склеротик |
| Стратег | горизонт 2–3 хода, чувство времени трека | — |
| Гений | низкая температура, точный риск и крафт | Склеротик |
| Склеротик | забывает наблюдения, свою ложь и обещания с вероятностью за раунд | Гений, Перфекционист |
| Параноик | низкое стартовое доверие, избегает общих Комнат, чаще сканирует | Филантроп |
| Эгоист | малый вес чужого успеха, вредит редко | Филантроп |
| Эгоцентрист | много Просьб, сильная обида на отказ | — |
| Филантроп | мораль +, охотно отдаёт и помогает | Психопат, Социопат, Эгоист, Барахольщик, Параноик |
| Социопат | взаимность безразлична, лжёт при выгоде | Филантроп |
| Психопат | готов к косвенному вреду (Двери, огонь, Декомпрессия, Капсулы), слабый страх | Филантроп |
| Потенциальный лжец | низкий порог лжи | — |
| Обидчивый | вред помнит вдвое дольше, скепсис почти не тает | — |
| Раздвоение личности | две личности (набор черт и знак морали) меняются по событиям или раз в N раундов | — |

Мораль: M ∈ [−100; +100].
- **Вес чужого успеха в полезности:** при M > 0 — альтруизм (M/100 × коэффициент). Около 0 — рациональный эгоизм. При M < 0 — злорадство: чужой успех вычитается, у −100 цель «никто, кроме меня».
- **Вред только косвенный:** персонажи не могут атаковать друг друга напрямую (стр. 17), поэтому злая мораль проявляется Дверьми, огнём, Декомпрессией, Самоуничтожением, Капсулами, Курсом, Двигателями и ложью.

## 5. Риски

| Риск | Мера |
|---|---|
| Бот видит скрытое через общий код | граница линтером + тест на подмену скрытого |
| Отказ движка раскрывает скрытое | бот не анализирует причину отказа |
| Зависание партии | предел шагов, безопасный Пас, тест «партия ботов до конца» |
| Шум Рации | лимиты, частота речи в настройках, свёртка повторов |
| Производительность на телефоне | бюджет 50 мс, Web Worker |
| Объём выпуска | шаги 1–4 полезны и без ботов, могут выйти патчами 0.7.x |
