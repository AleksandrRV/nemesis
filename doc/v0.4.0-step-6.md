# Этап 0.4.0, Шаг 6 — Смерть Чужих, Останки и Слабости

Версия **0.2.17**, схема состояния **10** (изменение контракта: `WeaknessCard.effect` — машинный эффект карты; слоты Планшета Чужих при подготовке наполняются 3 случайными картами): сохранения версии 0.2.16 не восстанавливаются.

Границы шага: смерть Чужих, Останки, подбор Тяжёлых объектов, Слабости и их боевые эффекты. Побег — Шаг 7, классовые карты — Шаг 8, Фаза Событий и развитие Улья — этап 0.5.0.

## 1. Отклонение от исходного плана (зафиксировано ревью)

Пункт плана «при гибели Королевы на пол дополнительно выкладывается жетон Яйца» **не реализован**: в `doc/rules.md` такого следствия смерти нет (стр. 1200–1210, 1398–1413). Яйца появляются на Планшете Чужих только в Фазу Событий и берутся в Улье (стр. 10). Ревью 0.4.0 прямо помечает «яйцо Королевы» ошибкой эксперимента E — вердикт: «обратные утверждения в задании не дают основания внедрять несуществующую механику». Смерть Королевы оставляет те же Останки, что и любой другой не-Личинка.

## 2. Смерть Чужого и Останки (стр. 20, 22)

`checkInjuryResult` при ранах не меньше Стойкости: миниатюра снимается, в `room.objects` кладётся `{ kind: 'INTRUDER_REMAINS', intruderType }` с сохраняемым id (`allocateEntityId`, без часов). **Личинка Останков не оставляет** — «удалите их миниатюры с поля» (стр. 20, 22; вердикт ревью). В журнал пишется публичное событие:

```ts
{ type: 'INTRUDER_KILLED', playerId, roomId, targetIntruderId, targetType, remainsObjectId: string | null }
```

## 3. Поднять Тяжёлый объект [1] (стр. 13, 22)

`ACTION_PICK_UP_OBJECT { objectId, discardCardIds }` — цена 1 карта Действия. Гейты: `UNKNOWN_PLAYER` → `HAND_SLOTS_FULL` (оба слота Рук заняты) → `OBJECT_NOT_AVAILABLE` (объекта нет в отсеке). Действие переносит **любой** Тяжёлый объект отсека — Труп Персонажа, Останки Чужого или Яйцо — в свободный слот Руки (`{ source: 'OBJECT', object }`). В Бою доступно: это базовое действие, а не Действие Комнаты (FAQ Actions 4). Событие журнала — `OBJECT_PICKED_UP`. Правила сброса объекта на пол вне Лаборатории (стр. 22) выведены в будущий шаг с картами Действий.

## 4. Слабости Чужих (стр. 21)

- В коробке **8 карт** (`WEAKNESS_CARDS`): 7 из транскрипта `doc/data/INTRUDERS.md` плюс «Вид на грани вымирания» из `doc/data/WEAKNESSES.md` — ревью 0.4.0: неполнота одного транскрипта не оправдывает потерю карты при наличии текста в другом предоставленном документе.
- Подготовка: колода тасуется потоком `cards`, **3 верхние** — в слоты Планшета Чужих (по одному на Труп / Яйцо / Останки) рубашкой вниз, остальные убираются «в коробку» (`decks.weaknesses` пуст).
- Карта несёт машинный `effect: WeaknessEffect`; санитайзер отдаёт слоты как `EMPTY`/`FACE_DOWN`/`REVEALED` — рубашка не раскрывает ни имя, ни текст.

### Применяемые эффекты (боевые, ревью 0.4.0: «нужны здесь»)

| Эффект | Правило | Где в движке |
| --- | --- | --- |
| Уязвимость к энергии | атака Энергооружием с ≥1 Раной даёт +1 Рану | `shoot.ts` (только Стрельба) |
| Вид на грани вымирания | Стойкость каждой вытянутой карты −1 | `checkInjuryResult` (Стрельба и Рукопашная) |
| Реакция на опасность | порог Внезапной атаки −1, но не ниже 1; «Зов» не атакует | `contact.ts` — `isSurpriseAttack` |
| Повадки атаки | Укус **Взрослой** — Лёгкая Травма вместо Тяжёлой (без правил мгновенной смерти) | `intruderAttacks.ts` |

Отложены до соответствующих механик: Уязвимость к огню и Восприимчивость к фосфатам (огонь в бою/Фазе Событий), Повадки движения (разрушение Дверей), Уязвимые места (пересекается с базовой таблицей граней — смысл появится с эффектами, читающими символ грани).

## 5. Лаборатория [2] «Изучите 1 объект» (стр. 16)

Исправляет дефекты прежней заглушки (ревью: сценарии D8/D9):

- в отсеке должен быть объект требуемого типа — **на полу или в руках любого Персонажа** отсека («например, в руках Персонажа»);
- `targetObjectKind` обязателен; слот без карты или уже раскрытая Слабость — отказ (`ROOM_ABILITY_NOT_ALLOWED` / `WEAKNESS_ALREADY_REVEALED`);
- **объект не удаляется** — ни с пола, ни из рук; опционально можно сбросить **свой** объект с руки без траты действия (`discardObjectAfterStudy`) — жетон возвращается в отсек (стр. 22);
- цена — 2 карты Действия (общий пайплайн `ACTION_ROOM_ABILITY`), в Бою запрещено (стр. 18).

## 6. Интерфейс

- Инспектор отсека: у каждого объекта на полу — кнопка «Поднять [1]» (активна при свободном слоте Рук и выделенной карте цены); в Лаборатории — кнопки «Изучить: …» только для типов, чьи Слабости ещё под рубашкой; блок «Слабости Чужих (Планшет)» — изученные открыты, рубашка честно анонимна.
- Журнал: «…убивает Взрослую особь! Жетон Останков — на полу отсека #N», «…поднимает Тяжёлый объект "Останки Чужого"»; окна боя при гибели упоминают жетон Останков, у Личинки — его отсутствие.
