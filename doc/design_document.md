## 1. Общее видение и цели

### 1.1. Описание
Пошаговый survival-хоррор: экипаж пробуждается от гибернации с амнезией, исследует модульный корабль (21 отсек, 29 коридоров, вентиляция), устраняет аварии, борется с Чужими (5 классов жизненного цикла), выполняет тайные личные/корпоративные цели и спасается через капсулы или анабиоз с прыжком к Земле.

### 1.2. Принципы
1. **Правила 1:1** — книга правил `doc/rules.md` + печатные компоненты `doc/original/` — единственный источник истины, без балансировок.
2. **Code-Only** — декларативный UI в коде (React + Tailwind + SVG), без GUI-редакторов.
3. **Автономия Соло** — игра в браузере без сервера/интернета (факт: `LocalInMemoryTransport` + `localStorage`).
4. **Устойчивость сессии** — автосохранение после каждого действия, восстановление с проверкой схемы 19.
5. **Zero Cheating** — клиент видит мир только через `filterStateForPlayer`.

## 2. Архитектура мира и сущности (факт v0.5.0)

### 2.1. Топология корабля (граф 21 узел, 29 коридоров)

```
[Мостик 001] ──(1)── [03] ── ... ── [Двигатель 01 021]
     │                     │                  │
  (2) коридор           (3)               (4)
     │                     │                  │
[04] ──(1)── [Криоотсек 011] ── ... ── [Двигатель 02 020]
                        │
                    [Вентиляция] — поле Технических Коридоров
                    (8 отсеков с входами: 2:[1,2],4:[2,3],5:[4],9:[3],14:[3],15:[4],19:[3,4],21:[2,3])
```

* **Узлы 21:** 5 особых напечатанных (Мостик 001, Криогенный 011, Машинные 019/020/021 — всегда исследованы, поиск запрещён) + 16 неособых слотов, куда кладутся тайлы: 11 «1» всегда + 5 случайных «2» из 9. На каждый неособый — 1 жетон Исследования из пула 20 (4 в коробку).
* **Свойства комнаты:** `id`, `definitionId`, `category` (SPECIAL/ROOM_1/ROOM_2), `isExplored`, `itemsCount`, `hasComputer`, `hasFire`, `hasMalfunction`, `hasSlime`, `hasDecompressionToken`, `occupants` (персонажи, Чужие, тяжёлые объекты).
* **Коридоры 29:** `id`, `fromRoomId`, `toRoomId`, `exits: {from,to}` (1–4 с каждой стороны), `doorState` OPEN/CLOSED/DESTROYED, `hasNoise` (макс 1), `techNumbers` (входы в вентиляцию). Парные коридоры между одной парой отсеков — одна запись с общим маркером Шума/двери (известное расхождение, зафиксировано тестом-снимком).
* **Технические коридоры:** не комната, персонажи не входят (кроме карты Механика «Технические коридоры [1]»), 1 общий слот шума `technicalCorridorNoise`, уход Чужого в вентиляцию — сброс ран, жетон в мешок Пула.

Код: `shipGraph.ts` (21/29), `roomDefinitions.ts` (5+11+9 с цветами), `shipGraphQueries.ts`.

### 2.2. Персонажи (6 базовых, Медик промо не реализован)

**Классы:** Капитан (синий), Пилот (зелёный), Механик (оранжевый), Солдат (красный), Скаут (фиолетовый), Учёный (голубой). Медик (малиновый) — промо из `roles.pdf`/`cards_base.pdf`, в коде отсутствует (документирован в `CHARACTERS.md`).

Структура `PlayerState`:

* `characterClass`, `color`, `orderNumber`.
* **Колода действий:** 10 уникальных карт на класс (всего 60), стоимость [0]–[2] + особая (стр. 13). Состав — `actionCards.ts`, точные тексты — `doc/data/CHARACTERS.md` v2.0.
* **Рука:** лимит 5 (6 в Каютах), карты Заражения — «мёртвый груз», нельзя оплачивать ими действия.
* **Сброс:** личный, туда же идут карты Заражения при получении.
* **Слоты рук:** ровно 2 под тяжёлые предметы/объекты (Труп, Яйцо, Останки). При попытке взять 3-й — решение `DISCARD_HEAVY_ITEM_FOR_NEW`.
* **Инвентарь:** скрытый пул не-тяжёлых предметов, без лимита, виден только цвет рубашки другим игрокам.
* **Квестовые предметы:** 2 горизонтальных (неактивных) — план этапа 0.6.
* **Травмы:** трек Лёгких 0–2 (3-я → Тяжёлая), слоты Тяжёлых 3 (4-я → смерть). 16 карт: 4 нога, 4 рука, 4 спина, 4 кровотечение.
* **Статус:** Слизь, Сигнал, Анабиоз, Капсула, Смерть, Труп.

Стартовые оружия (6): Револьвер 6, Дробовик 2, Обрез 2, Боевая винтовка 5, Энерговинтовка 4 (энерго), Пистолет 3 — `startingItems.ts`.

### 2.3. Чужие (5 классов)

1. **Личинка:** 1 рана, не вступает в Бой, при Контакте — заражение (карта Заражения в сброс + Личинка на планшет), повторная — ещё карта (FAQ Rules 12).
2. **Крипер:** 1 карта Стойкости, эволюционирует в Трутня по «Трансформация».
3. **Взрослая:** 8 миниатюр, 1 карта Стойкости, основа пула. При исчерпании фигур — отступают вне Боя, жетоны в мешок.
4. **Трутень:** 2 миниатюры, Стойкость сумма 2 карт, аура биоугрозы.
5. **Королева:** 1 миниатюра, Стойкость сумма 2 карт, босс, защищает кладку.

**Пул (27 жетонов):** 1 Пустой, 8 Личинок, 3 Крипера, 12 Взрослых, 2 Трутня, 1 Королева. В мешок при подготовке: 1 Пустой, 4 Личинки, 1 Крипер, 1 Королева, 3 Взрослых +1×игроков (1→4,5→8). Остальные — запас. Числа Внезапной атаки на обороте: Личинка 1, Крипер 1, Взрослые [2,3,4,4,1,2,3,1,2,3,4,1], Трутень 3, Королева 4 — `ADULT_ESCAPE_NUMBERS`.

Кубики: Бой d6 — 2×Промах, Хвост/Личинка/Крипер, Силуэты/Личинка/Крипер/Взрослая, 1 Рана, 2 Раны (в рукопашной =1). Шум d10 — 1,1,2,2,3,3,4,4, Тишина, Опасность.

Атаки Чужих 20 карт: Царапина 4, Укус 4, Когти 4, Хвост 2, Трансформация 2, Ярость 2, Слизь 1, Зов 1 — `intruderAttacks.ts`.

Код: `intruderPool.ts`, `intruderMiniatures.ts`, `combatDie.ts`, `noiseDie.ts`, `intruderAttacks.ts`, `contact.ts`, `intruderRetreat.ts`.

### 2.4. Предметы и крафт (90 +12 +6)

* **Красные 30:** Энергозаряд 5, Граната 5, Дымовая 4, Увеличенный магазин 4, Дрон-разведчик 4, Военные препараты 4, Приманка 4.
* **Жёлтые 30:** Изолента 6, Инструменты 6, Огнетушитель 5, Планы техкоридоров 5, Скафандр 4, Планы Немезиды 4.
* **Зелёные 30:** Бинты 6, Аптечка 5, Алкоголь 5, Одежда 5, Адреналин 5, Синтетическая еда 4.
* **Синие 12 (крафт):** Антидот (CHEM+CHEM) 3, Тазер (ELEC+POWER) 3, Огнемёт (TOOLS+CHEM) 4 боезапаса тяжёлый 3, Молотов (ALCOHOL+FABRIC) 3 — `crafting.ts`.

Правила: обычные — в инвентаре тайно, тяжёлые — в слотах рук видно всем, макс 2. Поиск [1]: -1 счётчик комнаты, 2 карты, взять 1, вторую под низ. В Улье и Слизь-комнате поиск запрещён. Создание [1]: сброс 2 карт с синими компонентами.

Код: `itemCards.ts`, `crafting.ts`, `startingItems.ts`, `search.ts`.

## 3. Игровой цикл и FSM (факт)

### 3.1. Структура раунда

```
НАЧАЛО РАУНДА
  I. ФАЗА ИГРОКОВ
    1. Добор до 5 (6 в Каютах)
    2. Жетон Первого Игрока влево (со 2-го раунда)
    [ЦИКЛ МИКРОХОДОВ] while не все спасовали:
      for player по очереди от Первого:
        if hasPassed continue
        2 действия / 1+пас / пас (сброс любых карт)
        if закончил ход в огне → Лёгкая Травма
  II. ФАЗА СОБЫТИЙ (9 шагов, стр.10)
    4. Время +1, Самоуничтожение +1 если запущено → проверка HYPERSPACE_JUMP/SHIP_EXPLODED, разблокировка капсул с жёлтой зоны
    5. Атаки Чужих: каждый Чужой в Бою атакует (цель — наименьшая рука, Заражение считается, при равенстве — жетон Первого)
    6. Урон от Огня: каждый Чужой в горящем отсеке 1 Рана + проверка Стойкости, 1 Яйцо на полу сгорает
    7. Карта События: Движение Чужих вне Боя по номеру коридора → текстовый эффект 19 вариантов
    8. Развитие Улья: жетон из мешка → 6 исходов
  Проверка конца: SHIP_EXPLODED/HULL_BREACH/HYPERSPACE_JUMP/NO_ACTIVE_CHARACTERS
```

### 3.2. Оплата действий
Стоимость [N] — сброс N карт действий с руки в личный сброс. Карта действия с текстом: сама карта + доплата. Заражение нельзя сбрасывать для оплаты.

### 3.3. Прерывания

```
[Движение] → {В Бою?} → Атака побега (от крупных к мелким, FAQ Rules 5) → {Выжил?}
          → {Дверь закрыта?} → ОТМЕНА
          → Перемещение → {Неисследована?} → Вскрыть тайл + жетон Исследования (эффект: Пожар/Поломка/Слизь/Двери/Тишина/Опасность)
          → {Пуста?} → Бросок Шума d10 → [1-4] маркер / шум есть → Контакт → сброс шума → жетон из мешка → BLANK/Личинка/миниатюра → {Карт на руке < числа?} → Внезапная атака
                     → [Опасность] → стянуть Чужих / шум во все коридоры
```

Очередь `interruptQueue` разыгрывается до пустой, пауза на `pendingDecision`.

## 4. Скрытая информация, блеф, доверие (факт + план)

### 4.1. Заявления (Claims)
Проверка Двигателя/Координат — тайное знание (истинный `isWorking` / `destination`), затем публичное заявление (можно солгать). `ClaimEvent` в журнале, санитайзер скрывает истину от других. Система заявлений — этап 0.8.0.

### 4.2. Сканер Заражения
Карта Заражения: `isInfected: boolean`. Визуализация — красный визор с помехами, слово ИНФЕКЦИЯ проступает при инфицированной. При инфекции — Личинка на планшет, карта не удаляется. Повторная при живой Личинке — смерть → Крипер. 27 карт: 7 инфицированных, 20 стерильных.

### 4.3. Цели
Старт: 1 Личная +1 Корпоративная втайне. Первый Контакт (первая миниатюра Чужого) — пауза, выбор 1 из 2, вторая удаляется лицом вниз. Победа: выполнить выбранную цель + выжить (Анабиоз с Землёй/Марсом для Карантина или Капсула). Колоды целей — заглушка в v0.5.0, реализация этапа 0.6–0.7.

## 5. ИИ ботов (план, Zero-Cheating)

Бот не имеет доступа к `GameState`, только `SanitizedGameState` + `BotBeliefState`:

```typescript
interface BotBeliefState {
  engineStatus: { [id: number]: 'UNKNOWN'|'BELIEVED_OK'|'BELIEVED_BROKEN' };
  coordinatesStatus: 'UNKNOWN'|'BELIEVED_EARTH'|'BELIEVED_OTHER';
  playerTrustScores: { [playerId]: number }; // 0 лжец .. 1 союзник
}
```

Utility Scoring U(a)=Σ w_i·S_i: Критический 100 (огонь/кровотечение), Высокий 80 (Чужой в комнате), Целевой 60 (сигнал/цель), Исследовательский 40 (поиск/разведка), Пас 10. A* с весами: шум +2, огонь +5, бой +10.

## 6. Окончание игры и победа (стр. 11, 17)

### 6.1. Триггеры немедленного конца
1. Время 15 — гиперпрыжок, все не в анабиозе погибают.
2. Самоуничтожение 8 (череп) — взрыв, все погибают.
3. 9-й Пожар или 9-я Неисправность — разрыв обшивки/взрыв, все погибают.
4. Все активные персонажи покинули игру (анабиоз/капсулы/смерть) — `NO_ACTIVE_CHARACTERS`.

### 6.2. Финальная валидация (план этапа 0.7)

```
[СТАРТ] → {Корабль цел?} → НЕТ → выжили только капсулы
        → ДА → [Двигатели] 2+ повреждены? → ВЗРЫВ, анабиоз погибает
             → [Курс] Земля? → анабиоз летит домой
                      → Марс + Карантин? → обладатель выживает
                      → иначе гибель
             → [Заражение] скан всех карт: есть ИНФЕКЦИЯ/Личинка? → замешать, взять 4 → есть Заражение? → гибель
             → [Цели] проверка персонального квеста → ПОБЕДА
```

## 7. Сохранение и автономность (факт)

* После каждого действия — сериализация в `localStorage` ключ `nemesis_active_game_session`.
* Соло: полный снапшот (граф 21/29, колоды, Чужие, сид, RNG счётчики).
* При старте — проверка `schemaVersion` 19, несовместимые не восстанавливаются.
* Журнал — часть состояния, версия 4→19.

## 8. UI/UX (факт)

### 8.1. Мобильная
* Центр: SVG-карта 21 гекс + 29 коридоров + вентиляция, pinch-zoom, перетаскивание, бейджи огня/поломки/слизи/предметов, маркеры шума/дверей, фишки игроков/Чужих с анимацией 750мс.
* Низ: выдвижная панель руки (HP, патроны, 2 слота рук, веер карт с ценой, мультиселект оплаты, счётчик 0/2).
* Модалки: действия комнат, поиск, бой, решения (белая колода, 1 из 2, сброс тяжёлого, цели, Подготовка 1 из 3, Пожарный контроль, Генератор, отдых, переброс).

### 8.2. Десктоп
* Левая: планшет персонажа.
* Центр: карта без постоянного зума.
* Правая: статус комнат, треки Времени/Самоуничтожения, пул Чужих, журнал.
* Низ: полоса руки с drag-and-drop оплаты.

### 8.3. Тач и вес
* Кликабельная область ≥44×44px.
* У каждой модалки — кнопка закрытия/отмены.
* Поле — вектор SVG, без растровых текстур, лёгкий билд.
