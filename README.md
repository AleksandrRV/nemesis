# Nemesis Digital

Неофициальная цифровая адаптация настольной игры **Nemesis** (автор Адам Квапинский, издатель Awaken Realms, 2018): партия в браузере. Правила готовят стол на 1–5 игроков; интерфейс пока ведёт одного персонажа — офлайн-соло без сети.

> **Это фанатский проект для личного использования.** Он не связан с правообладателями, не одобрен ими и не предназначен для коммерческого использования. Проект переносит оригинальную игру 1:1 и работает только с оригиналами — книгой правил, картами и артом; правовые вопросы в нём не рассматриваются (см. [NOTICE](NOTICE.md)).

Проект написан на TypeScript как два пакета: правила живут в общем ядре, а интерфейс общается с ним только действиями игрока и получает **отфильтрованное** состояние — то, что персонаж действительно может знать.

**Текущая версия: 0.5.0** — её же показывает HUD приложения: строка версии живёт в `package.json` и подставляется сборкой, а не правится в двух местах. История изменений — в [CHANGELOG](CHANGELOG.md), происхождение каждой таблицы данных — в [doc/sources/data-sources.json](doc/sources/data-sources.json).

## Что уже работает

- **Карта корабля**: 21 отсек и 29 коридоров, жетоны Дверей (открыта / закрыта / разрушена). Разрушенная Дверь терминальна — снова её не закрыть (стр. 17), жетонов Дверей 12, и при пустом запасе жетон переставляется с поля.
- **Подготовка партии на 1–5 игроков**: мешок Чужих (3 взрослых плюс по одному за каждого игрока), инверсная пара жетонов двигателей, Спасательные Капсулы по числу игроков (2–4), случайная карта Координат, жетоны Исследования по отсекам, шесть пресетов персонажей. Личные колоды действий (60 карт) и колоды предметов (Красная, Жёлтая, Зелёная по 30 карт, 12 создаваемых предметов), колода Заражения (27), Тяжёлых Травм (16) и Событий (20). Один и тот же сид всегда даёт одну и ту же партию.
- **Боевые данные (этап 0.4.0, Шаг 1)**: колода из 20 Атак Чужих с типизированными эффектами, стойкостью и символами атакующих; шесть граней кубика Боя и воспроизводимые броски через поток `combat`. Это контракт ядра, не готовый бой.
- **Плавные перемещения и Фаза Событий (этап 0.5.0, Шаг 9, v0.5.0)**: слой `BoardAnimationLayer` — интерполяция 750 мс от центра к центру, взлом Двери (вспышка + искры), уход в вентиляцию (стягивание к хабу), `prefers-reduced-motion` → растворение; кинематографичный оверлей «ФАЗА СОБЫТИЙ: РАУНД N» с 6 шагами (счётчики, атаки, огонь, карта События + движение, эффект, Улей), подсветкой отсеков и клавиатурой; 8 интеграционных тестов замкнутого цикла.
- **Развитие Улья (этап 0.5.0, Шаг 8)**: жетон из мешка потоком `bag` — Личинка→Взрослая в мешок, Крипер→Трутень, Взрослая/Трутень→броски Шума вне Боя, Королева→в Улей с Контактом или Яйцо на планшет (8), Пустой→Взрослая из запаса; каскады Шума/Контактов, пустой мешок — пропуск.
- **Текстовые эффекты карт Событий (этап 0.5.0, Шаг 7б)**: 19 эффектов — Охота, Защита кладки (Контакт EVENT), Выводок, Регенерация, Затаившиеся, Созревание, Разгром, Подготовка (выбор 1 из 3 Первым Игроком), Запах добычи/Шум в техкоридорах/Улей (шум причина EVENT, playerId null), Воспламеняемый раствор/Разрушающее пламя/Короткое замыкание/Утечка/Неполадка систем/Неисправность/Катапультирование (isDestroyed)/Открытие отсеков; судьба карт: удаление с замешиванием сброса, возврат, сброс.
- **Движение Чужих в Фазе Событий (этап 0.5.0, Шаг 6)**: Шаг 7а книги правил (стр. 10, 15) — верхняя карта Событий вытягивается лицом вверх и задаёт Движение: символы выбирают типы, номер — направление. Чужие в Бою остаются; открытый Коридор — переход, Закрытая Дверь разрушается сообща, вентиляция снимает миниатюру со сбросом Ран. Неисследованные отсеки не раскрываются, вход к Персонажу — Бой без Контакта.
- **Атаки Чужих в Фазе Событий (этап 0.5.0, Шаг 5)**: Шаг 5 книги правил (стр. 10, 20) — каждый Чужой в Бою атакует. Цель — наименьшая рука (Заражение считается), при равенстве — жетон Первого и часовая стрелка. Личинка инфицирует без карты, остальные тянут Атаку — символы попадания, 8 эффектов со Слабостями и смертью от 3-й Тяжёлой. Баннер сводки атак, полная гибель → NO_ACTIVE_CHARACTERS.
- **Оркестратор Фазы Событий (этап 0.5.0, Шаг 4)**: при всеобщем пасе Фаза по шагам книги правил. Время +1, Самоуничтожение +1 если запущено → HYPERSPACE_JUMP/SHIP_EXPLODED, разблокировка капсул с жёлтой зоны. Урон от огня: 1 Рана Чужому в горящем отсеке + проверка Стойкости, 1 Яйцо на полу сгорает.

- **Отступление Чужих (этап 0.5.0, Шаг 2)**: стрелка Отступления — карта События задаёт номер коридора и уходит в сброс без эффекта; открытый коридор — уход, закрытая дверь — разрушение, вентиляция — снятие и сброс Ран.
- **Колода Событий (этап 0.5.0, Шаг 1)**: 20 карт с эффектами, направлением 1-4/ANY и символами типов; флаги isDestroyedOnResolve (4) и isReshuffledIntoDeck (1). Тасуется потоком cards, добор закрыт числом, сброс лицом вверх.
- **Побег из Боя (этап 0.4.0, Шаг 7)**: Движение из отсека с Чужими — Побег (стр. 19): перед шагом каждый Чужой атакует в спину, от крупного к мелкому (FAQ Rules 5); погибший остаётся Трупом в исходном отсеке; диалог подтверждения и окно «Побег — атака в спину».
- **Останки и Слабости (этап 0.4.0, Шаг 6)**: смерть Чужого кладёт в отсек жетон Останков (Личинка — без Останков, Королева — без Яйца по ревью); действие [1] «Поднять Тяжёлый объект»; 8 карт Слабостей, 3 случайные изучаются в Лаборатории (объект с пола или из рук, объект сохраняется) и их боевые эффекты применяет движок.
- **Рукопашная атака (этап 0.4.0, Шаг 5)**: базовое действие `ACTION_MELEE` — карта Заражения до броска, грань «2 Раны» считается 1 Раной, промах отвечает Тяжёлой Травмой Персонажу (стр. 19, 21); проверка Стойкости и Отступление — общая процедура со Стрельбой.
- **Стрельба (этап 0.4.0, Шаг 4)**: действие «Стрельба» (`ACTION_SHOOT`) — Оружие из слота Рук, цена картой и Боезапасом, бросок кубика Боя, Раны против Стойкости Чужого (стр. 19–20) с накоплением ран на миниатюре; при ранах не меньше Стойкости миниатюра снимается, а стрелка Отступления у выжившего разыгрывается по карте События (Шаг 2 этапа 0.5.0).
- **Движок правил и Фаза Игроков (v0.3.0)**:
  - Цикл микрораундов: круговой порядок от первого игрока, выбор из 3 легальных вариантов (2 действия, 1 действие + пас, немедленный пас), блокировка спасовавших и переход в фазу событий при общем пасе.
  - Универсальная система оплаты действий сбросом карт действий с руки с абсолютным запретом сброса карт Заражения. Сброс карт Заражения разрешён только при обычном пасе.
  - Действие «Поиск» (`ACTION_SEARCH`): проверка отсека, выбор колоды в белых комнатах, взятие 2 карт, интерактивный выбор 1 карты через `pendingDecision` и возврат второй карты под низ колоды, списание счётчика предметов.
  - Действия 11 базовых отсеков (`ACTION_ROOM_ABILITY`): перезарядка энергооружия (Оружейная), отправка сигнала (Радиорубка), три режима лечения (Лазарет), пуск/остановка таймера самоуничтожения (Генератор), тушение пожаров (Пожарная безопасность), взятие яиц (Улей), раскрытие карт слабостей (Лаборатория), посадка в капсулы (Спасательные отсеки), сканирование и удаление инфекций ценой лёгкой раны и паса (Операционная).
- **Пользовательский интерфейс**: интерактивная SVG-карта с зумом и панорамированием, инспектор отсеков с контекстными кнопками обыска и действий консоли, нижняя панель карт руки с мультиселектом для оплаты и паса, выдвижная панель инвентаря и слотов рук, модальные диалоги выбора (`DecisionModal`), публичный журнал действий партии, панели выстрела и рукопашной атаки с окном результата (кубик Боя, карты Стойкости, ответные Травмы).
- **Честность среза**: двигатели и Координаты скрыты до личной проверки, невскрытый тайл не раскрывает свойства; чужие руки, сброс, инвентарь и приватные решения `pendingDecision` скрыты от других игроков через `filterStateForPlayer`.
- **Офлайн-соло**: партия сохраняется в браузере и продолжается после перезапуска, сеть для игры не требуется. Отказ движка показывается игроку понятной причиной.

## Быстрый старт

```bash
npm ci        # установка зависимостей воркспейсов по lock-файлу
npm run dev   # dev-сервер Vite: http://localhost:5173
```

Требования: Node.js 20+ (проверено на 22.22.3) и npm 10+.

В dev-сборке в HUD есть кнопка **dev-панели**: диагностика партии (сид, режим, срез отфильтрованного состояния), старт с заданным сидом и отладочные переключатели Дверей и Шума. В игровом интерфейсе читерских элементов нет, в продакшн-сборку панель не попадает, а отладочные действия движок в любом случае отклоняет вне dev-режима.

## Команды

| Команда                               | Что делает                                                       |
| ------------------------------------- | ---------------------------------------------------------------- |
| `npm run dev`                         | dev-сервер клиента с горячей перезагрузкой                       |
| `npm run build`                       | сборка ядра и клиента в `packages/*/dist`                        |
| `npm run verify`                      | тип-чек, ESLint, Prettier и тесты — одна проверка перед коммитом |
| `npm test`                            | тесты (vitest, проекты `shared` и `client`)                      |
| `npm run test:coverage`               | тесты с покрытием                                                |
| `npm run lint:fix` / `npm run format` | автоисправления линтера и форматирования                         |

## Структура

| Путь              | Что там                                                                                                                                       |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `packages/shared` | ядро: контракт `GameState`, данные (граф корабля, отсеки, рецепты, пресеты), движок правил и фильтр скрытой информации. Без DOM, React и сети |
| `packages/client` | интерфейс на React, нижний журнал действий, транспорт (`IGameTransport`), офлайн-партия и сохранение, стор                                    |
| `doc/`            | аудит, GDD, техстек, дорожная карта                                                                                                           |
| `AGENTS.md`       | регламент работы агентов и разработчиков в этом репозитории                                                                                   |

Как всё связано: клиент не меняет состояние партии сам — он отправляет действие через транспорт, движок ядра проверяет его по правилам, а наружу возвращается только представление игрока (`filterStateForPlayer`). Поэтому правила нельзя «обойти» через интерфейс, а скрытые данные не попадают в UI.

- **Не все колоды разыгрываются.** Цели пока остаются пустыми (этап 0.6–0.7). Колода Событий — 20 карт, Фаза Событий реализована полностью (9 шагов, 19 эффектов, Улей). Колода Атак — 20 карт, боевой контур исполнен. Состав колоды Событий ждёт физической сверки: транскрипт ранее перечислял 22 карты, в коде 20 по решению владельца 22.09.2026 — зафиксировано в [`doc/sources/data-sources.json`](doc/sources/data-sources.json) как `unverified`.
- **Данные поля ещё сверяются с физическими компонентами.** Пул жетонов Исследования (20 жетонов, 44 предмета) и числа Внезапной атаки на жетонах Чужих — из внешних переписей и подтверждений владельца, не из фото; топология Коридоров (29) и номера выходов читаются только с поля, парные Коридоры пока описаны одной связью. Все помечены в [`doc/sources/data-sources.json`](doc/sources/data-sources.json) статусами `EXTERNAL_UNVERIFIED` и `UNVERIFIED_BOARD`; пока сверки нет, бросок Шума на отсутствующий номер — Тишина.
- **Интерфейс ведёт одного персонажа.** Стол готовится на 1–5 игроков, но сетевой партии и смены активного игрока в UI ещё нет (этапы 10–11 дорожной карты).
- Реализованные механики соответствуют книге правил; номера страниц в комментариях («стр. 14») — это ссылки-ориентиры.

## Правила игры и источники

Единственный источник истины по механике — **оригинальная книга правил**, её текст лежит в репозитории: [`doc/rules.md`](doc/rules.md). К нему относятся все ссылки «стр. N» в коде и документации.

Проект переносит игру **1:1**: механики, порядок фаз, стоимости действий, структура колод, названия карт, отсеков и символов берутся из оригинала без упрощений и «балансировок»; отклонение от оригинала считается дефектом. Источники — только оригиналы: книга правил, оригинальные карты и оригинальный арт (без фанатских пересказов и самодельных подмен).

Утверждение «1:1» проверяемое, а не декларативное: у каждой таблицы данных есть запись в пакете источника [`doc/sources/data-sources.json`](doc/sources/data-sources.json) — откуда взято каждое число (строки `doc/rules.md`, подтверждение владельца компонентов, внешний источник), — а golden-тесты [`sources.golden.test.ts`](packages/shared/src/data/sources.golden.test.ts) сверяют код с этим файлом. Что ещё не сверено с физическими компонентами, помечено в пакете статусами `USER_CONFIRMED`, `EXTERNAL_UNVERIFIED` и `UNVERIFIED_BOARD` и перечислено в списке `unverified`: пока такой пометки нет, непроверенное не выдаётся за проверенное.

Правовые аспекты в проекте не рассматриваются: это некоммерческий фанатский проект для личного использования, юридическая экспертиза не проводилась и не планируется, а агентам и разработчикам запрещено заниматься правовыми вопросами вместо реализации игры. Подробнее — в [NOTICE](NOTICE.md).

## Качество

Перед коммитом проект проверяется целиком:

```bash
npm run verify   # типы + линтер + формат + тесты
```

Входные `TEMP/EXPERT_*_STAGE_4.md` исключены только из команд форматирования: их patches и номера строк сохраняются без изменений. Код приложения, типы и тесты остаются под полными проверками.

На версии **0.5.0** проходят **989 тестов в 82 файлах**, включая полный боевой контур этапа 0.4.0 (Контакты, Внезапные атаки, Стрельба, Рукопашная, Останки, Слабости, Побег, классовые карты), полный цикл Фазы Событий этапа 0.5.0 (9 шагов: счётчики Времени/Самоуничтожения, гиперпрыжок/взрыв, Атаки Чужих в Бою с выбором цели, урон от огня Чужим и Яйцам, Движение Чужих по карте События с разрушением Дверей и уходом в вентиляцию, 19 текстовых эффектов с судьбой карт, Развитие Улья 6 исходов, баннер сводки, анимация перемещений 750мс, оверлей Фазы Событий, интеграционные тесты 3 циклов). Полные `verify` и production build проходят. Покрытие боевых модулей (V8, 0.4.0): Стрельба, Рукопашная, Побег, Слабости, кубик Боя, санитайзер — 100% строк и ветвей; Контакты и Атаки — 100% строк (ветви 92–96%); классовые карты — 88% строк.

Тесты лежат рядом с кодом (`*.test.ts`): инварианты данных и подготовки партии, RNG, правила движка, журнал, фильтр скрытой информации, сохранение и транспорт. Полный отчёт покрытия — `npm run test:coverage`; покрытие новых модулей не означает 100% покрытия всего приложения.

Каждый push и pull request прогоняет те же проверки в CI (`.github/workflows/ci.yml`): `npm ci`, `npm run verify`, продакшн-сборка и отдельный шаг, который падает, если в бандл попали строки отладочной панели.

Проект некоммерческий и фанатский: код предоставляется «как есть» для личного и образовательного использования, права на игру остаются у правообладателей. Статус проекта, источники и правило «1:1» — в [NOTICE](NOTICE.md).
