# ДОКУМЕНТАЦИЯ ПО СЛАБОСТЯМ ЧУЖИХ (WEAKNESSES)
# Проект: Nemesis Digital

**Версия документа:** 1.1 (Актуализация под 0.5.0)  
**Источник:** `packages/shared/src/data/weaknesses.ts` (8 карт), `doc/data/WEAKNESSES.md` — транскрипт, книга правил стр. 21, `doc/sources/data-sources.json#weakness-cards`.

При подготовке 3 случайные карты Слабостей кладутся рубашкой вниз в слоты Планшета Чужих (`WEAKNESS_SLOT_COUNT = 3`): по одному на Труп Персонажа (`CORPSE`), Яйцо (`EGG`) и Останки Чужого (`INTRUDER_REMAINS`). Остальные — в коробку. Изучение — действием Лаборатории [2] (объект с пола **или** из рук, объект сохраняется; `discardObjectAfterStudy` — опциональный сброс без действия; повтор — `WEAKNESS_ALREADY_REVEALED`).

Раскрытая Слабость (`isRevealed = true`) видна в `SanitizedGameState` как `REVEALED`, закрытая — `FACE_DOWN`; движок применяет эффект через предикат `isWeaknessRevealed` (`logic/weaknesses.ts`).

## 8 КАРТ СЛАБОСТЕЙ (`WEAKNESS_CARDS`)

| Код (`effect`) | Название | Текст |
| --- | --- | --- |
| `VULNERABLE_SPOTS` | Уязвимые места | При атаке Взрослых Особей «Силуэты» считается 1 Раной. |
| `FIRE_WEAKNESS` | Уязвимость к огню | Урон от Огня (фаза Событий/оружие) +1 Рана. |
| `DANGER_REACTION` | Реакция на опасность | Порог Внезапной атаки −1 (мин. 1). |
| `ENERGY_WEAKNESS` | Уязвимость к энергии | Энергооружие при ≥1 Раны — ещё 1 Рана. |
| `MOVEMENT_BEHAVIOR` | Повадки движения | Закрытые Двери ломают только Королева/Трутень. |
| `PHOSPHORUS_SUSCEPTIBILITY` | Восприимчивость к фосфатам | Огнетушитель/Пожаротушение → Отступление +1 Рана. |
| `ATTACK_BEHAVIOR` | Повадки атаки | Укус Взрослой — Лёгкая вместо Тяжёлой Травмы. |
| `EDGE_OF_EXTINCTION` | Вид на грани вымирания | Стойкость всех Чужих −1. |

Боевые эффекты (энергия, стойкость, порог, укус) применяются на 0.5.0; огонь/фосфаты/двери — когда соответствующие механики разыгрываются полностью. В транскрипте `INTRUDERS.md` было 7 карт — 8-я (`EDGE_OF_EXTINCTION`) добавлена по `WEAKNESSES.md` (замечание ревью 0.4.0).

Проверка — `sources.golden.test.ts` (ожидание 8) и `weaknesses.test.ts`.
