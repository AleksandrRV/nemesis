# Nemesis Digital

Неофициальная цифровая адаптация настольной игры **Nemesis** (автор Адам Квапинский, издатель Awaken Realms, 2018): партия в браузере. Правила готовят стол на 1–5 игроков; интерфейс пока ведёт одного персонажа — офлайн-соло без сети.

> **Это фанатский проект для личного использования.** Он не связан с правообладателями, не одобрен ими и не предназначен для коммерческого использования. Проект переносит оригинальную игру 1:1 и работает только с оригиналами — книгой правил, картами и артом; правовые вопросы в нём не рассматриваются (см. [NOTICE](NOTICE.md)).

Проект написан на TypeScript как два пакета: правила живут в общем ядре, а интерфейс общается с ним только действиями игрока и получает **отфильтрованное** состояние — то, что персонаж действительно может знать.

**Текущая версия: 0.5.0** — её же показывает HUD приложения: строка версии живёт в `package.json` и подставляется сборкой, а не правится в двух местах. История изменений — в [CHANGELOG](CHANGELOG.md), происхождение каждой таблицы данных — в [doc/sources/data-sources.json](doc/sources/data-sources.json).

## Что уже работает

- **Карта корабля**: 21 отсек (5 особых напечатанных + 16 неособых слотов) и 29 коридоров, жетоны Дверей (открыта / закрыта / разрушена). Разрушенная Дверь терминальна — снова её не закрыть (стр. 17), жетонов Дверей 12, и при пустом запасе жетон переставляется с поля. Отдельный узел «Поле Технических Коридоров» (стр. 9, 16) с трассами вентиляционных шахт.
- **Подготовка партии на 1–5 игроков**: мешок Чужих (3 взрослых плюс по одному за каждого игрока), инверсная пара жетонов двигателей, Спасательные Капсулы по числу игроков (2–4), случайная карта Координат, жетоны Исследования по отсекам (16 из 20, 4 в коробку), шесть пресетов персонажей. Личные колоды действий (60 карт) и колоды предметов (Красная, Жёлтая, Зелёная по 30 карт, 12 создаваемых предметов), колода Заражения (27), Тяжёлых Травм (16) и Событий (20). Один и тот же сид всегда даёт одну и ту же партию.
- **Плавная анимация перемещений и кинематографичная Фаза Событий (этап 0.5.0, Шаг 9)**: слой `BoardAnimationLayer` скользит фишками по траектории коридора (`cubic-bezier`, 750 мс) без мгновенных скачков — движение игрока, движение Чужих по карте События, Отступление по стрелке и уход в вентиляцию; взлом Закрытой Двери и растворение в узле Технических Коридоров с эффектами; статика скрывается на время перехода, `prefers-reduced-motion` заменяет движение растворением. Оверлей «ФАЗА СОБЫТИЙ: РАУНД N» показывает шесть шагов Фазы Событий по порядку движка с анимированными шкалами времени/самоуничтожения, картами Атак, картой События и жетоном Улья; янтарная подсветка затронутых отсеков на карте.
- **Развитие Улья (этап 0.5.0, Шаг 8)**: Шаг 8 книги правил (стр. 10, 31) — из мешка Пула Чужих потоком `bag` тянется 1 жетон: Личинка/Крипер — удаление «в коробку» с заменой на Взрослую/Трутня, Взрослая/Трутень — броски Шума персонажами вне Боя по очереди ходов, Королева — миниатюра в Улей с Контактом (источник `EVENT`) либо Яйцо на Планшет (вместимость 8), Пустой — Взрослая из запаса; каскады Шума и Контактов разыгрываются до нового раунда; пустой мешок — честный пропуск `HIVE_DEVELOPMENT_SKIPPED`. Визуал Чужих обновлён: масштабы классов, аура биоугрозы у Трутня/Королевы, адаптивная сетка при 3+ типах, рамка «В Бою».
- **Текстовые эффекты карт Событий (этап 0.5.0, Шаг 7б)**: Шаг 7б книги правил (стр. 10, `doc/data/EVENTS.md`) — 19 эффектов с итогом `EVENT_EFFECT_RESOLVED`: Охота, Защита кладки (Контакт источник `EVENT`), Выводок, Регенерация, Затаившиеся, Созревание, Разгром, Подготовка (`CHOOSE_EVENT_CARD` — выбор 1 из 3, `EVENT_CARD_CHOSEN`), Шум-группа и Пожар/Неисправность-группа с распространением, Катапультирование Капсулы (`isDestroyed`), Открытие отсеков; судьба карт — удаление с замешиванием сброса, возврат «Неисправности» в колоду, публичный сброс; исчерпание запасов Пожара/Неисправности взрывает корабль.
- **Автономное Движение Чужих (этап 0.5.0, Шаг 7а)**: Шаг 7а книги правил (стр. 10, 15) — верхняя карта Событий вытягивается лицом вверх (`EVENT_CARD_DRAWN`) и задаёт Движение: символы выбирают типы, номер — направление; Чужие в Бою остаются; открытый Коридор — переход (`INTRUDER_MOVED`), Закрытая Дверь разрушается сообща, номер вентиляции снимает миниатюру со сбросом Ран и возвратом жетона в Пул; неисследованные отсеки не раскрываются, вход к Персонажу объявляет Бой без Контакта.
- **Атаки Чужих в Фазе Событий (этап 0.5.0, Шаг 5)**: Шаг 5 книги правил (стр. 10, 20) — каждый Чужой в Бою с Персонажами атакует; цель — Персонаж с наименьшей рукой (Заражение считается), при равенстве — жетон Первого Игрока и порядок по часовой стрелке; Личинка инфицирует без карты Атаки, остальные тянут карту Атак Чужих — символы решают попадание, восемь эффектов исполняются со Слабостями и смертью от третьей Тяжёлой Травмы; каждая атака — `EVENT_PHASE_ATTACK_RESOLVED`, баннер сводки атак.
- **Оркестратор Фазы Событий (этап 0.5.0, Шаг 4)**: при всеобщем пасе Фаза Событий исполняется по шагам книги правил (стр. 10). Маркер Времени двигается в Фазе Событий; последнее красное поле немедленно завершает партию гиперпрыжком — вне Анабиоза все гибнут от перегрузок (стр. 11). Самоуничтожение двигается вместе со Временем: с жёлтой зоны все Капсулы разблокируются автоматически и процесс необратим, последнее деление с черепом взрывает корабль. Каждый Чужой в горящем отсеке получает 1 Рану с проверкой Стойкости — гибель с Останками или Отступление по карте События, одно свободное Яйцо на полу сгорает (стр. 20, 25).
- **Локация «Технические коридоры» на карте (этап 0.5.0, Шаг 3)**: Поле Технических Коридоров (стр. 9, 16) — отдельный узел-хаб под корпусом корабля: индустриальная решётка, датчик давления, аварийная разметка; к каждому красному маячку входа проложены пунктирные трассы вентиляционных шахт; Шум в вентиляции пульсирует тревогой на узле и дублируется на всех входах; Чужие, ушедшие в вентиляцию при Отступлении, на миг видны силуэтами во тьме узла; клик открывает панель локации с состоянием и доступами.
- **Отступление Чужих в бою (этап 0.5.0, Шаг 2)**: стрелка Отступления на карте проверки Стойкости разыгрывается по колоде Событий (стр. 20): верхняя карта задаёт номер Коридора и уходит в сброс без розыгрыша эффекта; открытый Коридор — миниатюра уходит в соседний отсек; Закрытая Дверь разрушается, Чужой остаётся (FAQ, правило 8); номер вентиляции снимает миниатюру и сбрасывает Раны (стр. 16); исход — `INTRUDER_RETREATED`.
- **Колода Событий (этап 0.5.0, Шаг 1)**: 20 карт Событий с машинными эффектами, направлением Движения Чужих (номер Коридора 1–4 или `ANY` у «Подготовки») и символами Чужих верхнего блока; флаги уничтожения и замешивания карты при розыгрыше; колода тасуется при подготовке через поток `cards`, порядок добора закрыт числом, сброс — лицом вверх.
- **Побег из Боя (этап 0.4.0, Шаг 7)**: Движение из отсека с Чужими — Побег (стр. 19): перед шагом каждый Чужой атакует в спину, от крупного к мелкому (FAQ Rules 5); погибший остаётся Трупом в исходном отсеке; диалог подтверждения и окно «Побег — атака в спину» (`ESCAPE_ATTACK_RESOLVED`).
- **Останки и Слабости (этап 0.4.0, Шаг 6)**: смерть Чужого кладёт в отсек жетон Останков (Личинка — без Останков, Королева — без Яйца по ревью); действие [1] «Поднять Тяжёлый объект» (`ACTION_PICK_UP_OBJECT`); 8 карт Слабостей, 3 случайные изучаются в Лаборатории (объект с пола или из рук, объект сохраняется) и их боевые эффекты применяет движок.
- **Рукопашная атака (этап 0.4.0, Шаг 5)**: базовое действие `ACTION_MELEE` — карта Заражения до броска, грань «2 Раны» считается 1 Раной, промах отвечает Тяжёлой Травмой Персонажу (стр. 19, 21); проверка Стойкости и Отступление — общая процедура со Стрельбой (`MELEE_RESOLVED`).
- **Стрельба (этап 0.4.0, Шаг 4)**: действие «Стрельба» (`ACTION_SHOOT`) — Оружие из слота Рук, цена картой и Боезапасом, бросок кубика Боя, Раны против Стойкости Чужого (стр. 19–20) с накоплением ран на миниатюре; при ранах не меньше Стойкости миниатюра снимается, а стрелка Отступления у выжившего разыгрывается по карте События (`SHOOT_RESOLVED`).
- **Движок правил и Фаза Игроков (v0.3.0)**:
  - Цикл микрораундов: круговой порядок от первого игрока, выбор из 3 легальных вариантов (2 действия, 1 действие + пас, немедленный пас), блокировка спасовавших и переход в фазу событий при общем пасе.
  - Универсальная система оплаты действий сбросом карт действий с руки с абсолютным запретом сброса карт Заражения. Сброс карт Заражения разрешён только при обычном пасе.
  - Действие «Поиск» (`ACTION_SEARCH`): проверка отсека, выбор колоды в белых комнатах, взятие 2 карт, интерактивный выбор 1 карты через `pendingDecision` и возврат второй карты под низ колоды, списание счётчика предметов.
  - Действия 11 базовых отсеков (`ACTION_ROOM_ABILITY`): перезарядка энергооружия (Оружейная), отправка сигнала (Радиорубка), три режима лечения (Лазарет), пуск/остановка таймера самоуничтожения (Генератор), тушение пожаров (Пожарная безопасность), взятие яиц (Улей), раскрытие карт слабостей (Лаборатория), посадка в капсулы (Спасательные отсеки), сканирование и удаление инфекций ценой лёгкой раны и паса (Операционная).
- **Пользовательский интерфейс**: интерактивная SVG-карта с зумом и панорамированием, инспектор отсеков с контекстными кнопками обыска и действий консоли, нижняя панель карт руки с мультиселектом для оплаты и паса, выдвижная панель инвентаря и слотов рук, модальные диалоги выбора (`DecisionModal` — 9 типов решений: `CHOOSE_OBJECTIVE`, `CHOOSE_SEARCH_ITEM`, `CHOOSE_WHITE_ROOM_DECK`, `CHOOSE_EVENT_CARD`, `DISCARD_HEAVY_ITEM_FOR_NEW`, `ROOM_FIRE_CONTROL_TARGET`, `ROOM_GENERATOR_ACTION`, `CHOOSE_REST_CONTAMINATION_DISCARD`, `REROLL_COMBAT_DIE`), публичный журнал действий партии с подсветкой сущностей, панели выстрела/рукопашной и окно Контакта.
- **Честность среза**: двигатели и Координаты скрыты до личной проверки, невскрытый тайл не раскрывает свойства; чужие руки, сброс, инвентарь и приватные решения `pendingDecision` скрыты от других игроков через `filterStateForPlayer` (мешок/запас — составом, колоды — числом, порядок добора не видит никто, карты Заражения скрывают `isInfected` до сканирования).
- **Офлайн-соло**: партия сохраняется в браузере (`sessionStorage`, ключ `nemesis-session`, версия схемы 19) и продолжается после перезапуска, сеть для игры не требуется. Отказ движка показывается игроку понятной причиной.

## Быстрый старт

```bash
npm ci        # установка зависимостей воркспейсов по lock-файлу
npm run dev   # dev-сервер Vite: http://localhost:5173
```

Требования: Node.js 20+ (проверено на 22.22.3) и npm 10+.

В dev-сборке в HUD есть кнопка **dev-панели**: диагностика партии (сид, режим, срез отфильтрованного состояния), старт с заданным сидом и отладочные переключатели Дверей и Шума. В игровом интерфейсе читерских элементов нет, в продакшн-сборку панель не попадает, а отладочные действия движок в любом случае отклоняет вне dev-режима.

## Структура

| Путь              | Что там                                                                                                                                                                               |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `packages/shared` | ядро: контракт `GameState` (схема 19), данные (граф корабля, отсеки, рецепты, пресеты), движок правил (FSM + 9 шагов Фазы Событий) и фильтр скрытой информации. Без DOM, React и сети |
| `packages/client` | интерфейс на React, нижний журнал действий, транспорт (`IGameTransport` → `LocalInMemoryTransport`), офлайн-партия и сохранение, стор, анимация карты и оверлей Фазы Событий          |
| `doc/`            | аудит, GDD, техстек, дорожная карта, журнал, карта проекта, пакет источника                                                                                                           |
| `AGENTS.md`       | регламент работы агентов и разработчиков в этом репозитории                                                                                                                           |

Как всё связано: клиент не меняет состояние партии сам — он отправляет действие через транспорт, движок ядра проверяет его по правилам, а наружу возвращается только представление игрока (`filterStateForPlayer`). Поэтому правила нельзя «обойти» через интерфейс, а скрытые данные не попадают в UI.

## Ограничения

- **Цели и финальный подсчёт побед — этап 6–7.** Колода Целей раздаётся, выбор при Первом Контакте реализован, но финальный валидатор победы (проверка двигателей, координат, заражения и условий целей) — следующий этап. Тексты целей — в [`doc/data/OBJECTIVES.md`](doc/data/OBJECTIVES.md).
- **Дополнительные комнаты «2» — часть действий на заглушках.** Базовые 11 комнат категории «1» полностью реализованы; из 9 дополнительных 5 попадают в партию, но часть их эффектов (например, полная логика декомпрессии, наблюдение) — этапы 6–7.
- **Данные поля ещё сверяются с физическими компонентами.** Пул жетонов Исследования (20 жетонов, 44 предмета) и жетоны Чужих пришли из внешних переписей компонентов и подтверждений владельца проекта, но не из фото в репозитории; топология Коридоров и номера выходов читаются только с поля и не сверялись, поэтому парные Коридоры пока описаны одной связью. Все эти места помечены в [`doc/sources/data-sources.json`](doc/sources/data-sources.json) статусами `EXTERNAL_UNVERIFIED` и `UNVERIFIED_BOARD` со списком `unverified`; пока сверки нет, бросок Шума на номер, которого нет среди выходов отсека, разыгрывается как «Тишина».
- **Интерфейс ведёт одного персонажа.** Стол готовится на 1–5 игроков, но сетевой партии и смены активного игрока в UI ещё нет (этапы 10–11 дорожной карты).
- Реализованные механики соответствуют книге правил; номера страниц в комментариях («стр. 14») — это ссылки-ориентиры.
- Состав колоды Событий (20 карт) ждёт физической сверки: транскрипт перечислял 22 карты, в коде 20 — расхождение зафиксировано в [`doc/sources/data-sources.json`](doc/sources/data-sources.json) (`unverified` таблицы `event-cards`).

## Правила игры и источники

Единственный источник истины по механике — **оригинальная книга правил**, её текст лежит в репозитории: [`doc/rules.md`](doc/rules.md). К нему относятся все ссылки «стр. N» в коде и документации.

Проект переносит игру **1:1**: механики, порядок фаз, стоимости действий, структура колод, названия карт, отсеков и символов берутся из оригинала без упрощений и «балансировок»; отклонение от оригинала считается дефектом. Источники — только оригиналы: книга правил, оригинальные карты и оригинальный арт (без фанатских пересказов и самодельных подмен).

Утверждение «1:1» проверяемое, а не декларативное: у каждой таблицы данных есть запись в пакете источника [`doc/sources/data-sources.json`](doc/sources/data-sources.json) — откуда взято каждое число (строки `doc/rules.md`, подтверждение владельца компонентов, внешний источник), — а golden-тесты [`sources.golden.test.ts`](packages/shared/src/data/sources.golden.test.ts) сверяют код с этим файлом. Что ещё не сверено с физическими компонентами, помечено в пакете статусами `USER_CONFIRMED`, `EXTERNAL_UNVERIFIED` и `UNVERIFIED_BOARD` и перечислено в списке `unverified`: пока такой пометки нет, непроверенное не выдаётся за проверенное.

Правовые аспекты в проекте не рассматриваются: это некоммерческий фанатский проект для личного использования, юридическая экспертиза не проводилась и не планируется, а агентам и разработчикам запрещено заниматься правовыми вопросами вместо реализации игры. Подробнее — в [NOTICE](NOTICE.md).

## Качество

Перед коммитом проект проверяется целиком:

```bash
npm run verify   # типы + линтер + формат + тесты
```

Входные `TEMP/EXPERT_*_STAGE_4.md` исключены только из команд форматирования: их patches и номера строк сохраняются без изменений. Код приложения, типы и тесты остаются под полными проверками.

На версии **0.5.0** проходят **989 тестов в 82 файлах**, включая полный цикл этапов 0.4.0–0.5.0: Контакты (Личинка, статус Боя), Внезапные атаки, Стрельба/Рукопашная (кубик Боя, Стойкость, Отступление по карте События), Останки и Слабости (Лаборатория), Побег с атаками в спину, классовые боевые карты («Прицельный огонь» с перебросом, «Стрельба очередью», «Заградительный огонь»/«Огонь на подавление», «Адреналин»), всю Фазу Событий (счётчики Времени/Самоуничтожения, Атаки Чужих с выбором цели, урон от огня, Движение Чужих, 19 текстовых эффектов с судьбой карт, Развитие Улья с каскадами Шума/Контактов), плавную анимацию перемещений (`BoardAnimationLayer`, `useBoardAnimations`) и кинематографичный оверлей Фазы Событий (`EventPhaseModal`). Полные `verify` и production build проходят. Покрытие боевых модулей (отчёт V8, 0.4.0): Стрельба, Рукопашная, Побег, Слабости, кубик Боя и санитайзер — 100% строк и ветвей; Контакты и колода Атак — 100% строк (ветви 92–96%); классовые боевые карты — 88% строк (не покрыты только защитные `EngineError` на искажённые параметры действия).

Тесты лежат рядом с кодом (`*.test.ts`): инварианты данных и подготовки партии, RNG, правила движка, журнал, фильтр скрытой информации, сохранение и транспорт. Полный отчёт покрытия — `npm run test:coverage`; покрытие новых модулей не означает 100% покрытия всего приложения.

Каждый push и pull request прогоняет те же проверки в CI (`.github/workflows/ci.yml`): `npm ci`, `npm run verify`, продакшн-сборка и отдельный шаг, который падает, если в бандл попали строки отладочной панели.
