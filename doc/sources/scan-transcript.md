# Транскрипт сканов оригинала

Источник `pnp-scans` в `doc/sources/data-sources.json`. Здесь записано то, что прочитано со сканов
в `doc/original/`, с указанием файла и страницы PDF. Сканы без текстового слоя, всё прочитано
визуально при 250–300 dpi (Этап 0 плана `doc/fix-plan-scans.md`, задача С0-1), сверка 28.09.2026.

Правила чтения:

* «стр. N» — страница PDF-файла, не книги правил.
* Лица и обороты в PnP-листах идут парами страниц; оборот зеркален по строке.
* Символы Чужих (Планшет Чужих, книга правил стр. 21; карты Атак): **Крипер** — «C»;
  **Взрослая Особь** — S-волна из двух дуг; **Трутень** — трёхлучевая спираль; **Королева** — спираль
  с кольцами. Личинки нет ни на одной карте Событий и Атак.
* Грани кубика Боя (памятка `cards_base.pdf`, стр. 37; наклейки `dices.pdf`): пустая красная грань —
  промах; «C» — Крипер; S-волна — Взрослая Особь; один прицел — 1 Рана; два прицела — 2 Раны.
