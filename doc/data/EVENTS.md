## 1. Правила розыгрыша карты События (стр. 10, шаг 7)

1. **Движение Чужих (верхний блок).** Двигаются только Чужие тех типов, чьи символы есть на карте, и только
   вне Боя (в отсеке нет живого Персонажа). Каждый идёт в Коридор с номером карты (1–4).
   * Коридора с таким номером в отсеке нет — Чужой остаётся на месте.
   * В Коридоре Закрытая Дверь — Дверь становится Разрушенной, все идущие в неё Чужие остаются (стр. 17).
   * Номер ведёт ко Входу в Технические Коридоры — миниатюра снимается с поля, Раны сбрасываются, жетон
     возвращается в Пул Чужих (стр. 16).
   * Неисследованный отсек при входе Чужого не раскрывается (стр. 15); вход к Персонажу — Бой без Контакта (стр. 18).
   * Символа Личинки нет ни на одной карте: Личинки картой События не двигаются.
2. **Текстовый эффект (нижний блок)** — после движения; итог публикуется записью `EVENT_EFFECT_RESOLVED`
   (`EventEffectOutcome`, по варианту на эффект).
3. **Судьба карты.**
   * «УДАЛИТЕ эту карту из игры и замешайте сброс в колоду Событий» — 4 карты: карта уходит из игры, сброс
     замешивается под колоду потоком `cards`.
   * «Затем замешайте эту карту обратно в колоду Событий» — «Неисправность».
   * Остальные 15 карт — в публичный сброс `decks.events.discard`.

Пустая колода перед добором замешивает сброс потоком `cards` (детерминированно по сиду). Отступление в бою
(стр. 20) тоже вытягивает карту События: используется только её направление, эффект не разыгрывается.

## 3. Реализация эффектов в движке

| Эффект | Исход | Как исполняется |
|---|---|---|
| Защита кладки | `PROTECT_NEST` | «Столкновение» — Контакт (стр. 18): прерывание `CONTACT_INTERRUPT` с источником `EVENT` для каждого Персонажа в Улье или с Яйцом в руках. |
| Выводок | `BROOD` | Яйцо с Планшета; Персонаж в Улье без карт Действий на руке (карты Заражения не считаются, стр. 12) Инфицирован — Личинка на Планшет и 1 карта Заражения (стр. 20); никого — жетон Личинки из запаса в мешок. |
| Регенерация | `REGENERATION` | Каждый Чужой на поле сбрасывает 2 Раны (при одной — одну). |
| Разгром | `RAMPAGE` | Неисправность в отсеки со Взрослой, Трутнем или Королевой; последний маркер — Разрыв обшивки. |
| Затаившиеся | `HIDDEN` | Чужие вне Боя сняты с поля, их жетоны — в мешок. |
| Созревание | `MATURATION` | Носители Личинки гибнут, Крипер в их отсек. Затем каждый Персонаж на борту (не в Анабиозе и не в Капсуле, стр. 11) берет 4 карты из своей колоды Действий (пустая колода замешивает сброс, стр. 10), сканирует все карты Заражения на руке; при ИНФЕКЦИИ — Личинка на Планшет. Взятые карты сбрасываются. Сканирование — запись `CONTAMINATION_SCANNED` с источником `MATURATION`. |
| Воспламеняемый раствор | `FLAMMABLE_MIXTURE` | Пожар в Криогенный Отсек; если уже горит — в соседние отсеки. |
| Охота | `HUNT` | Взрослые вне Боя — в соседний отсек с Персонажем, из нескольких — с меньшим номером; Закрытая Дверь не пропускает. |
| Пожирающее пламя | `DEVOURING_FLAME` | Счетчик Предметов горящих отсеков → 0, затем Пожар в соседние отсеки. |
| Запах добычи | `PREY_SCENT` | Шум в каждый Коридор без Шума у отсеков с Персонажами со Слизью. |
| Неисправность | `MALFUNCTION` | Неисправность в исследованный отсек с наименьшим номером; карта замешивается в колоду. |
| Шум в технических коридорах | `NOISE_TECH_CORRIDORS` | Маркер Шума на поле Технических Коридоров; если уже есть — бросок кубика Шума для каждого Персонажа у Входа. |
| Улей | `HIVE` | Исследованный Улей: Шум в каждый его Коридор без Шума. |
| Открытие отсеков | `OPEN_COMPARTMENTS` | Закрытые Двери открываются, Разрушенные — нет. |
| Разрушающее пламя | `DESTRUCTIVE_FLAME` | Неисправность в горящие отсеки, затем Пожар в соседние. |
| Катапультирование капсулы | `ESCAPE_POD_EJECTION` | Капсула с наименьшим номером уничтожена. |
| Короткое замыкание | `SHORT_CIRCUIT` | Неисправность в Желтые отсеки с Компьютером. |
| Утечка охладителя | `COOLANT_LEAK` | Неисправный Генератор запускает Самоуничтожение. |
| Неполадка систем жизнеобеспечения | `LIFE_SUPPORT_MALFUNCTION` | Неисправность во все Зеленые отсеки. |

Огонь во всех трех «огненных» картах распространяется одной функцией: только через Коридоры без Закрытой
Двери, Технические Коридоры в граф Коридоров не входят. Девятый маркер Пожара взрывает корабль (стр. 17).
