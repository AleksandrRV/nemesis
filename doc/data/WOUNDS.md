# ДОКУМЕНТАЦИЯ ПО ТЯЖЕЛЫМ ТРАВМАМ (WOUNDS)
# Проект: Nemesis Digital

**Версия документа:** 1.1 (Актуализация под 0.5.0)  
**Источник:** Колода Тяжёлых Травм — `packages/shared/src/data/seriousWounds.ts` (16 карт), `doc/sources/data-sources.json#serious-wounds`.

Каждый персонаж имеет трек Лёгких травм (0–2). Третья Лёгкая травма → Тяжёлая Травма; прямая атака Чужого может нанести Тяжёлую сразу. При получении 4-й Тяжёлой Травмы персонаж **немедленно умирает** (стр. 21). Если вытягивается карта Травмы, которая у персонажа уже есть — эффект не суммируется, но карта занимает слот (приближая лимит). Травмы можно «Обработать» (перевернуть рубашкой вверх — эффект снимается, слот остаётся) и затем «Вылечить» (удалить) в Лазарете или предметами.

## КОЛОДА ТЯЖЁЛЫХ ТРАВМ (16 карт, по 4 копии каждого типа)

Всего 4 эффекта, каркас — `SERIOUS_WOUND_CARDS`:

1. **ТРАВМА НОГИ (4 копии, `SERIOUS_WOUND_LEG_*`)**  
   *Эффект:* С этого момента цена Действия «Побег» равна 2 (базовая 1, стр. 19).  
   *Сброс:* маркер состояния на треке — не применяется, пока карта не снята.

2. **ТРАВМА КИСТИ / РУКИ (4 копии, `SERIOUS_WOUND_ARM_*`)**  
   *Эффект:* С этого момента цена использования ваших Предметов увеличена на 1 (если предмет стоил 0 — стал 1).  
   *Сброс:* Аналогично — действует пока карта не обработана.

3. **ТРАВМА СПИНЫ / ТЕЛА (4 копии, `SERIOUS_WOUND_BODY_*`)**  
   *Эффект:* В начале Фазы Игроков вы добираете на руку до 4 карт вместо 5 (стр. 21; в коде — `getPlayerHandLimit`).  
   *Критично ограничивает экономику ходов.*

4. **КРОВОТЕЧЕНИЕ (4 копии, `SERIOUS_WOUND_BLEEDING_*`)**  
   *Эффект:* Каждый раз, когда вы пасуете во время Фазы Игроков, вы получаете 1 Лёгкую Травму (стр. 21).  
   *Заставляет постоянно получать урон за окончание раунда; требует немедленной перевязки.*

Карты различаются только `id` (`*_1` … `*_4`), `name`/`description` и `isTreated = false` при раздаче; при «Обработке» `isTreated` становится `true`, при «Лечении» карта удаляется. Подготовка — `createInitialDecks` тасует 16 карт потоком `cards`.

Проверка — `packages/shared/src/data/sources.golden.test.ts` (таблица `serious-wounds`, ожидание 16).
