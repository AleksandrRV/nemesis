# Этап 0.4.0, Шаг 8 — Сквозная интеграция, защита информации, выпуск v0.4.0

Версия **0.4.0** (выпуск этапа), схема состояния **12**: `SHOOT_RESOLVED` получил публичные флаги `rerolled` / `burstAmmoSpent` / `rifleBonusApplied`, журнал — событие `ACTION_CARD_DRAWN`, контракт действий — `PlayCardActionPayload.combat` (типизированные параметры встроенного боя). Сохранения версии 0.2.18 не восстанавливаются.

## 1. Классовые боевые карты (стр. 19, 24–28)

Каждая карта — **атомарное действие** «разыграть карту + встроенный бой» (одна транзакция `processAction`; откат — целиком, «действие не сгорает»):

| Карта | Правило | Реализация |
| --- | --- | --- |
| Солдат, «Прицельный огонь» | Стрельба + 1 переброс кубика Боя | Выстрел приостанавливается решением `REROLL_COMBAT_DIE` по **выпавшей грани** (кубик бросается открыто, стр. 18); оплата и Боезапас списаны до решения; KEEP оставляет грань, REROLL бросает новую (журнал: `rerolled: true`) |
| Солдат, «Стрельба очередью» | Сбросьте весь Боезапас винтовки: +1 Рана за каждые 2 ед. | Один выстрел, весь Боезапас уходит (включая ед. выстрела — FAQ Actions 8), `floor(потрачено/2)` доп. Ран; журнал: `burstAmmoSpent` |
| Солдат, «Заградительный огонь» | 1 Боезапаса; переместите себя **и/или** другого без Атак Чужих | 1–2 переноса, каждый — обычное `movePlayer` (вскрытие и Шум работают, Внеочередных атак нет — стр. 19 «изменяют правила Побега») |
| Капитан, «Огонь на подавление» | 1 Боезапаса; себя **ИЛИ** другого | Ровно 1 перенос; попытка двух — честный отказ, транзакция атомарна |
| Скаут, «Адреналин» | Стрельба **или** Побег и возьмите карту | Добор проверяется заранее (пустые колода и сброс — отказ до действия); добор — после выстрела/атак и Шума, перед завершением хода; Побег оплачивает цену Движения как обычно |

Бонус **Боевой винтовки** (описание предмета, стартовое Оружие Солдата): выстрел с ≥1 Раной добавляет ещё 1 — центрально в `performShoot`, работает во всех режимах (FAQ Actions 8 подтверждает суммирование с очередью). Взаимно исключим с «Уязвимостью к энергии» (винтовка не Энергооружие).

Отклонений от книги нет; за рамками шага — небоевые классовые карты (этапы 0.5.x).

## 2. Защита информации (Sanitizer)

Проверено тестами (санитайзер + интеграция): порядок колоды Атак Чужих закрыт числом (`drawPileCount`), сброс лицом вверх — свершившиеся факты боя (стр. 9, шаг 11; стр. 20); мешок и запас жетонов — только состав по типам (стр. 6, шаг 10); в журнале — только розыгранные факты: вытянутые карты Стойкости публичны, потому что выкладывались лицом вверх.

## 3. Интеграционные тесты (`combat.test.ts`)

Полный боевой цикл через FSM: вход в занятый отсек (Бой без нового Контакта) → три выстрела (1 < 3, 2 < 3, 3 ≥ 3) → гибель и Останки → подбор [1] → «Огонь на подавление» (отход без атак). Плюс: честный отказ без Боезапаса (партия не меняется), рукопашная с гарантированным Заражением и Тяжёлой Травмой за промах, цензура представления. Специализированные случаи покрыты юнит-файлами Шагов 3–7 (Контакты/повторный шум/очистка Коридоров — `contact.test.ts`, порог Внезапной атаки — `weaknesses.test.ts`, Стойкость и Останки — `shoot.test.ts`/`weaknesses.test.ts`, Побег — `escape.test.ts`).

## 4. Интерфейс

- `ShootModal`: переключатель «Режим выстрела» — базовый, «Прицельный огонь», «Стрельба очередью», «Адреналин»; режимы доступны только при карте в руке.
- `DecisionModal`: диалог переброса — выпавшая грань, «Перебросить» / «Оставить грань».
- `DisengagePanel` (инспектор): выбор Оружия для сброса Боезапаса, назначение себе, у Солдата — перенос другого Персонажа.
- `EscapeConfirmDialog`: вариант «Бежать с Адреналином [цена: 1, взять карту]» при карте в руке.
- Журнал: «берёт карту Действия в руку»; окно боя показывает «• переброс» и «очередью сброшено N»; бонус винтовки виден в сумме Ран.
- Рефакторинг лимита строк: `carefulMoveModel.ts`, `RoomStatusGrid.tsx`, `FloorObjectsPanel.tsx`, `DisengagePanel.tsx` — поведение инспектора прежнее.
