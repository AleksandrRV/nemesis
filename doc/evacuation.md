# Эвакуация: Камеры Анабиоза и Спасательные Капсулы — Этап 7, задачи 1–2

Правила: стр. 11 (окончание игры), стр. 12 (важные моменты: синие поля, первая смерть, Самоуничтожение), стр. 24–26 (Спасательные отсеки, Система блокировки капсул, Криогенный отсек, Спасательные Капсулы). Финальный Валидатор Победы (задача 3, 0.7.0) — `logic/endgame.ts`, описан в README и CHANGELOG 0.7.0.

## 1. Камеры Анабиоза

**Открытие.** Камеры открываются, когда маркер Времени достигает первого синего поля «8» (позиция 7, `map_full.jpg`): `timeTrackPosition ≥ HIBERNATION_OPENS_AT_TIME` (`data/evacuation.ts`). В этот момент пишется публичная запись `HIBERNATION_OPENED`.

Сверено с полем (Этап 5): зелёное «15» — позиция 0, белые «14»…«9» — позиции 1–6, синие «8»…«1» — позиции 7–14, прыжок — 15 (`data-sources.json#board-tracks`, scan-transcript §13).

**Действие Криогенного отсека [2]** (стр. 26):

1. Проверки:
   * Камеры открыты;
   * в отсеке нет Чужих;
   * общие правила Действий комнат: нет Неисправности, Персонаж не в Бою.
2. Бросок кубика Шума (`NOISE_ROLL_INTERRUPT` с `forceRoll` — бросок идёт, даже если в отсеке есть другие Персонажи).
3. `HIBERNATION_ATTEMPT_INTERRUPT`: если после Шума (и Контакта) в отсеке оказался Чужой, попытка сорвана. Иначе:
   * `isInHibernation = true`, миниатюра снимается с поля;
   * Персонаж выходит из активной игры, его ход сразу передаётся дальше.
4. Запись журнала `HIBERNATION_ATTEMPTED { success }`.

Пока кто-то в Анабиозе, нельзя запустить Самоуничтожение (остановить можно, стр. 24). Гиперпрыжок убивает всех на борту, кроме тех, кто в Анабиозе; при запущенном Самоуничтожении корабль уничтожается вместе с Анабиозом (стр. 24).

## 2. Спасательные Капсулы

**Разблокировка** — четыре пути:

| Способ | Где в коде |
| --- | --- |
| Первая смерть Персонажа | `characterDamage.ts`, было и раньше |
| Первое жёлтое поле Самоуничтожения «3» (позиция 3, `SELF_DESTRUCT_IRREVERSIBLE_AT`) | `eventsPhase.ts` |
| Система блокировки капсул [2] — новое | переключает замок выбранной Капсулы |
| Ключ эвакуации (квест Пилота) | через общий `togglePodLock` |

Каждое переключение замка пишется в журнал записью `ESCAPE_POD_TOGGLED`.

**Посадка — Действие Спасательного отсека A/B [2]** (стр. 24):

1. Нужна Разблокированная, не улетевшая Капсула своего отсека со свободным местом (всего мест 2); в отсеке нет Чужих.
2. Бросок Шума, затем `ESCAPE_POD_BOARDING_INTERRUPT`. Если в отсеке оказался Чужой, посадка сорвана.
3. После посадки:
   * Персонаж занимает место и снимается с поля отсека (`boardedPodId`, `boardedRound`);
   * игроку сразу предлагается решение `ESCAPE_POD_LAUNCH_CHOICE`: **запустить немедленно** или **ждать**.

**Ожидание в Капсуле** (стр. 26). Пока Персонаж в Капсуле, в свой ход он может только одно из трёх (действие `ACTION_ESCAPE_POD`):

* `LAUNCH` — запустить. Доступно только в раунде после посадки;
* `EXIT` — выйти без траты Действия и продолжить ход;
* `STAY` — ждать дальше, это автоматический Пас.

Остальные действия движок отклоняет с объяснением.

**Запуск.** Все, кто в Капсуле, покидают корабль (`hasEscapedInPod`), Капсула помечается `isLaunched`. Запись журнала `ESCAPE_POD_LAUNCHED`. Если в Капсуле ждал напарник, он улетает вместе с запустившим.

**Выброс из Капсулы.** Если в Спасательный отсек попадает Чужой, ждущие возвращаются в отсек (`guardEscapePods` проверяется после каждого прерывания). Если «Катапультирование капсулы» уничтожает Капсулу, сидящие в ней тоже возвращаются. Запись `ESCAPE_POD_EXITED` с причиной.

**Конец игры.** Если на борту не осталось активных Персонажей (`NO_ACTIVE_CHARACTERS`), по стр. 11 маркер Самоуничтожения переносится на череп, если оно запущено (взрыв: гибнут все на борту, включая Анабиоз), иначе маркер Времени — на последнее поле (гиперпрыжок: гибнут все вне Анабиоза). Ждущие в Капсулах остаются на борту: гиперпрыжок и взрыв их убивают. Затем выжившие проходят проверки Финального Валидатора (`resolveEndgame`).

**Известное ограничение.** Чужие, которые перемещаются картами Событий, выбрасывают ждущих из Капсулы на ближайшей проверке, то есть после текущего шага Фазы Событий, а не мгновенно. Атаки этого шага ждущих в Капсуле не задевают.

## 3. Интерфейс

**Инспектор отсека** (`components/evacuation/EvacuationActions.tsx`):

* **Криогенный отсек** — мини-трек Времени: серые, синие и красное деления, текущий маркер, сколько сдвигов осталось до открытия. Кнопка «Войти в Камеру Анабиоза [2]» требует подтверждения («уснуть до конца игры»); если войти нельзя, указана причина.
* **Спасательный отсек** — карточки Капсул: номер, замок, два места с именами сидящих, кнопка «Сесть в Капсулу №N [2]».
* **Система блокировки капсул** — все Капсулы с кнопками «Разблокировать / Заблокировать [2]».

**Пульт Капсулы** (`EscapePodConsole.tsx`) — центральный диалог. Сразу после посадки: «Запустить немедленно» / «Ждать напарника». В следующие ходы: «Запустить», «Выйти», «Ждать дальше (Пас)».

**Кинематограф** (`EvacuationCinematic.tsx`):

* **Старт Капсулы:** корпус дрожит, горит факел двигателя, Капсула уходит вверх сквозь поток звёзд, затем надпись «КАПСУЛА №N СТАРТОВАЛА».
* **Анабиоз:** «дышащая» камера стазиса, иней по краям, надпись «АНАБИОЗ».

**Прочее:**

* **Шапка:** индикатор «АНАБИОЗ ЧЕРЕЗ N» / «АНАБИОЗ ОТКРЫТ».
* **Планшет:** статус «В Капсуле».
* **Журнал:** все новые события в понятных формулировках.
